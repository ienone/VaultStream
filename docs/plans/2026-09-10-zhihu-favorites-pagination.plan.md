# 知乎收藏同步续页

状态：本计划续页范围已实现并验证，详见同名 process；不代表全量平台验收完成。

真实收藏预览有 50 条，限制 3 条抓取却返回空游标；当前 fetcher 忽略输入 cursor，每轮从首个收藏夹 offset=0 开始。目标是在单次上限下完整推进所有收藏夹，并复用现有任务的成功提交/失败保留游标规则。

使用收藏夹 ID 与已消费条目 offset 组成内部游标，不增加平台 API 或自动同步开关。非法游标或已消失收藏夹明确报错，不静默跳页。页内达到上限应从实际消费位置续读；已到收藏夹末尾则转到下一收藏夹，全部结束才返回 None。

验收：模拟外部 API 页，真实 fetcher 连续小批量读取无漏项；真实已登录收藏连续两批只读验证。禁止批量导入或发布。
