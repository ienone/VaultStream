# Telegram 订阅与阅读体验

状态：进行中。

## 目标

优先同步用户已加入且通知开启的频道，复用动态流的兴趣筛选、保留期和收录操作。Saved Messages 单独进入收藏库。按 Telegram 可定位的转发关系追溯原文、合并同源消息，保留转发者附加内容；缺少来源时前端不显示来源占位或诊断标签。

## 实施顺序

1. 获取开发者应用凭据并完成用户登录；会话文件作为秘密保存在数据目录。用户不需要各自注册应用。
2. 接入账号频道枚举、有效通知设置、增量消息和媒体处理，复用已有发现源开关与调度。
3. 处理转发、引用、相册和收藏语义；在真实账号授权后验收订阅选择、重复同步、编辑与删除边界。
4. 全局检查前端文案与内容层级，优化竖屏图文、横屏阅读和文章模板；通过实际界面验收。

## 验收边界

不新增单元测试。保留可重放的端到端操作及结果；登录前可完成代码、静态检查与本地界面验收，真实账号同步必须明确区分未验收与已成功。
