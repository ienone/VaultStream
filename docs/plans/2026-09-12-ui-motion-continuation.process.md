## 有效范围与执行约束

- 当前重心是 UI / UX：先判断独立页面、方向性弹层或原位展开，再处理信息层次、空间、圆角、对齐、键盘和动效。
- 人工验收主要检查界面与交互过程；常规业务逻辑使用代码检查及必要专项。复用有效结果，不为纯样式反复跑全套回归或双端构建。
- Web 和 Android 按适用宽度、横竖屏、明暗、大字号取样；不做折叠屏专项。组件模拟事件不替代原生手势，截图不替代动画过程，构建不替代交互验收。
- Agent、文本、视觉三个角色在本任务切换为 `deepseek-flash`，三项基础实调成功；摘要与 Embedding 保持原配置。历史调用不代表当前供应商状态或完整回答质量。
- 用户停止 OCR 接入后，本地 OCR 代码、接口、UI、依赖、权重、专项及样本已撤除。PDF 原生文本保留；未来 OCR 按飞桨等 API 另行设计，不作为本期完成条件。
- 不创建 worktree，不提交、推送、部署；真实副作用仍遵循明确授权和既有控制面。临时样本不代表真实平台质量，凭据不得进入记录。

## 页面、主导航与返回

- 详情采用平台标准路由；只有匹配真实来源卡片才注册共享头部 Hero。共享过渡保留两端测量布局，修复缩回小卡片时溢出；删除媒体辅助栏等重复入场动画。
- 全屏图集使用平台路由，保留透明来源与拖动退出；减少动画禁用 Hero 并直接切页。
- 自动化、分发和规则采用真实父子路由，移除按 URL 模拟返回；返回保留标签和父页状态。重选主分支沿实际 Navigator 返回，遇到草稿或保存中 guard 停止，普通分支切换保留草稿。
- 根弹窗关闭后，系统返回处理标记结合活动路由及祖先 guard 决定，修复直接退出 Activity；隐藏分支不再阻止首页回桌面预览，可见表单 guard 继续有效。
- `frontend/tool/dependencies/ensure_inactive_branch_back_navigation.dart` 修正依赖中隐藏 Shell 的 PopScope，接入开发说明及三个 CI workflow。上游结构改变时脚本明确失败，不能静默跳过；未来上游修复后移除脚本。
- 事件和任务结果移至根路由，复用播放外壳；修复内容→事件、内容回执→任务触发重复导航键断言及 Web 空白。真实往返、来源滚动与暂停会话保留已验证。
- 设置单栏采用标准列表／分区导航栈，系统返回先回列表并保留位置；宽屏分区不独立参与返回，保留 query 深链。主导航语义与正文隔离，修复导航可见却无法读屏访问。

## 弹层、草稿与焦点

- `AdaptiveFormDialog` 统一限宽、形状、边距和焦点可见性；普通高度固定操作区，短屏将操作放入同一滚动流，不替换输入子树。
- `AppFilterMenu` 统一根菜单、选中标记、键盘和减少动画；局部 Material 与裁切解决底色逃离圆角、滚动后绘制到顶部栏背后的问题。
- `PredictiveBackDialog` 仅接管当前可返回弹窗；最大缩小 4%、位移 16dp，撤回复位，中途再次接管从当前位置继续。提交再次检查 PopScope，减少动画不位移。
- 共享表单、PDF 阅读工具、日期层、12 处确认／标签弹窗及宽屏保存／模板／批量主面已接入。业务层继续负责草稿和保存中 guard，不由共享组件猜测提交策略。
- 推送目标类型及规则匹配模式换用独立弹出路由的固定选项控件，返回只关闭选项，不退出底层表单。
- 内容、规则、事件和笔记的退出确认保留草稿；保存中禁止重复操作与退出，失败保留输入。笔记冲突使用明确中文反馈。
- 规则路由 onExit 处理浏览器历史返回；继续编辑恢复原 URL 和草稿。内容／规则编辑另有 beforeunload 提醒；Chrome 已触发提示，但自动化立即确认刷新，人工取消刷新未验收。
- 规则保存后 provider 已释放时不再 invalidateSelf，避免成功写入被误报失败。
- 笔记及事件编辑在确认路由 completed 后恢复原控件焦点，修复输入、光标尚在但软键盘不恢复的时序问题。

## 播放器、后台控制与画中画

- 队列使用同一滚动容器的 SliverReorderableList，支持长队列边缘滚动，DragBoundary 保持浮层在安全区。30 项受控样本证明排序／取消／跨屏触控，不证明 30 份媒体解码。
- 加载、失败及待播选择去掉固定高度；短空间操作可滚动。视频保持真实比例，横屏按实际可用空间分配两栏；控制条移到画面下方，音频与详情连续滚动，短屏 mini player 不因固定高度溢出。
- 进度采用可操作滑块；Web 启动脚本仅补齐 Flutter 输出名称的 aria-labelledby 关联，不接管输入、不新增第二套滑块。
- audio_service／audio_session 接入同一全局会话、队列、倍速和定位。通知不发布签名资源 URL；暂停释放前台标记，停止清理系统会话。初始化期间主动暂停后不再被晚到回调自动播放。
- Android 36 上 60 秒音频退桌面约 23 秒、熄屏续播约 8 秒，锁屏播放／暂停／定位、通知返回及下一项切视频通过。该结果不证明长媒体、物理耳机或进程回收。
- 原生菜单开合保留同一视频视图；Web 根 PageRoute 观察排除普通 PopupRoute，修复菜单变黑。Web 延迟挂载和路由交接由最新播放意图恢复，主动暂停使旧恢复回调失效。
- Web 三轮菜单开合保留同一 video 节点且不产生暂停／移除，跨页及快速往返续播通过；部分 350ms 采样仍无节点，不称完全无缝。
- Android PiP 复用现有解码器与 AudioServiceActivity，singleTask 避免重复 Activity；按可见播放状态自动进入，小窗关闭暂停，展开恢复来源。暂停、音频、仅听声音不自动进入。
- 等窗口实际缩小再切纯视频布局，原生不采用 Web 的跨帧挂载等待；按实际能力禁用 seamless resize，撤回无效的 TextureView 切换。三次连续进出及回桌面手势取消通过，展开起点黑帧仍存在。
- 书签时间与菜单置首行、完整笔记位于下方；保存失败保留草稿，重复提交及未保存退出受保护。真实网络中断／重连仍未验收。
