# 迁移管理与模型结构化输出收敛

- 新库按 ORM 建表并补充 FTS/SSE，再标记 Alembic 版本；已有库由 Alembic 增量升级。移除全量结构快照、启动补列、自建版本表及旧独立迁移脚本；现有库均为测试数据，不保留旧库接管或历史兼容流程。
- 通用解析、巡逻评分与内容聚合使用已有 LangChain 的 Pydantic 结构化输出，不新增 Agent 框架、正则回退或输出修复重试。
- 保留业务权限、外部副作用确认、解析人工修订保护；不调用真实模型或平台。
- 复用仓库已有测试库验收新库初始化、增量升降级与重复启动，不新增临时数据库文件；用模拟 HTTP 边界验收真实模型客户端的结构化请求与失败传播。
- 临时验收用后删除，运行既有回归与 API/schema 检查，仅更新现有使用文档。
