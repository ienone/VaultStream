本目录只记录计划。计划不是现状文档；完成后必须和对应 process 一起移入 `archive/`。

## 命名规则

- `YYYY-MM-DD-short-name.plan.md`
- `YYYY-MM-DD-short-name.process.md`

## Plan 必填章节

- 背景
- 目标
- 非目标
- 关联文档
- 变更范围
- 实施步骤
- 验收标准
- 风险

## Process 必填章节

- 状态
- 实际执行记录
- 偏离计划
- 验证结果
- 后续问题
