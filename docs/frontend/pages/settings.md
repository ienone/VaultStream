# 设置页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/settings/settings_page.dart`
- 路由：`/settings`

## 用户任务与当前界面

设置按账号与平台、AI 与发现、推送与通知、外观与系统四个分区组织。用户可以配置服务器连接、平台凭证与健康、模型能力、发现来源、同步策略、Bot/群组、主题和媒体归档策略。

账号与平台分区既展示健康摘要，也提供实际控制：未登录时可发起二维码登录；凭据存在时可检测、更新登录或清除 VaultStream 保存的登录信息。Bilibili、小红书、微博和知乎使用相同的前端会话交互，但各自的平台协议由后端驱动实现。

设置项包含普通编辑、开关、枚举、敏感凭证、连通性测试和需要确认的重置/退出动作。模型“已配置”、健康检查和真实连通性测试必须分别表达。

## 自适应行为

- 宽屏同时显示分区导航和当前分区。
- 窄屏先选择分区，再进入全屏分区内容；返回时回到分区列表。
- 表单限制阅读宽度，低频高级参数默认折叠。

## 承担职责

- 全局、低频、用户可控的配置。
- 当前代码中的账号与平台连接入口；迁移完成前仍由这里承接。
- 二维码登录状态、平台安全验证入口和明确的失效修复动作。
- 能力状态和真实测试入口。

## 不承担职责

- 不展示完整运行历史或复杂收藏同步工作流。
- 不暴露后端尚未实现的策略占位。
- 不把自动化领域操作复制到设置中。

## API 关联

- 领域：`../../backend/api/agent-system-events.md`、`../../backend/api/automation-delivery.md`
- 敏感字段不得出现在日志、URL query 或普通错误文本中。
- 前端只轮询会话状态并展示后端生成的二维码；不读取或导入浏览器 Cookie、Local Storage 或密码。
