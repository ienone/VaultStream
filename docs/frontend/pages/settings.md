# 设置页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/settings/settings_page.dart`
- 路由：`/settings`

## 用户任务与当前界面

设置包含服务器连接、内容处理、AI 模型、内容筛选、通知、外观六个全局分区，对应 `connection`、`processing`、`automation`、`discovery`、`push`、`system`。媒体归档并入内容处理，不再单设页面。订阅来源位于 `/sources`，跨平台目标位于推送工作区；规则编辑内的目标管理使用弹窗，保留规则草稿。

单平台收藏同步的开关、预览与执行归入账号详情；全平台操作、全局策略和运行记录在 `/sources/sync`。解析、归档、摘要和索引开关在 `/settings?tab=processing` 对应阶段；分发模式在分发页；Cookie 保活在账号列表。设置不再复制这些控制面。

平台账号健康、扫码连接、检测、解绑和 Bilibili 手动凭据已迁入来源工作区 `/accounts`，设置不再重复管理账号对象。服务器连接分区只负责后端 API 地址、VaultStream 访问密钥、服务器连通性和网络代理。

服务器明确返回 `invalid_api_token` 时，客户端清除失效的本地认证并回到连接页；旧请求的迟到响应不得清除后来保存的新凭据。连接表单支持短屏和键盘压缩下滚动。

设置项包含普通编辑、开关、枚举、敏感凭证、连通性测试和需要确认的重置/退出动作。模型“已配置”、健康检查和真实连通性测试必须分别表达。

自动化处理页提供真实的“自动语义索引”开关：关闭后后端在内容入库/解析的 post-ingest 阶段停止创建索引任务和调用 embedding provider；它不删除已有索引，也不禁用用户显式发起的手动重建。

“内容理解/摘要”只在自动化处理页提供一个开关并写入 `enable_auto_summary`；“内容生成”区只配置摘要模型，不再重复展示同一个开关。关闭后 post-ingest 跳过自动摘要，内容详情中的用户显式生成动作仍保持独立。

RAG 索引状态中的失败项重试通过设置领域的 typed action provider 发起，页面不再直接拼装语义重建请求或解析动态 `run_id`。

自动化处理页提供真实的“解析队列处理”开关：关闭后解析 worker 不再领取后续任务，但用户仍可捕获内容并将任务留在 pending 队列；重新开启后继续处理。已经进入执行中的任务不会被该开关强制中断。

存储设置中的“自动归档远程媒体”及图片、视频子开关同样直接约束后端处理入口；质量、数量和视频体积限制会传给实际归档处理器。关闭只影响后续归档，不删除已有本地媒体，也不强制中断已经开始的下载。

“Cookie 保活”开关约束每一次计划中的平台检查，而不只是应用启动时决定是否创建任务。关闭后不再访问平台或生成保活结果/账号通知；重新开启无需重启后端，在下一调度点恢复。已经开始的检查不会被强制中断。

分发模式选择“暂停”后，后端会停止新的自动审批、规则刷新产生的自动审批、入队、worker 消费和 Agent 批量推送；规则失效时仍允许把旧的自动审批撤回待审，人工审核不受影响。

通知分区提供应用内周期摘要开关、6 小时/12 小时/每日/每周间隔和立即生成入口。立即生成调用真实摘要 API，并明确区分“已创建摘要”和“本周期没有新变化”；它不把确定性活动汇总描述成 AI 总结。

Bot 配置、服务控制与本平台群组管理归入 Telegram／QQ 账号详情；跨平台推送目标分区复用同一目标控件。操作仍由既有 typed action provider 发起；页面不直接拼 endpoint、payload 或动态响应字段。后端外部进程/网络动作已进入可注入 service，并通过 typed 结果携带运行类型、run ID、状态与错误；配置已保存和 Bot 已在线仍分别表达。

## 自适应行为

- 页面按自身可用宽度使用共享工作区断点；能同时容纳分区导航和内容时显示双栏，否则先选择分区，再进入分区内容。
- 宽屏左侧为 NavigationDrawer 分区导航，右侧是包含标题与正文的连续表面；正文居中限宽。没有中间竖线、内层圆角框和重复的“设置分区”标题。分区列表只显示名称与识别图标。
- 宽屏分区标题位于详情面板的标准顶部栏；表单在其下居中限宽，与其他对象详情使用相同的标题层级。
- 表单限制阅读宽度，低频高级参数默认折叠。来源短表单按内容收缩，不强制手机全屏或桌面固定高度；共享表面负责整表滚动，短横屏和键盘压缩空间时仍能滚动到操作区，切换尺寸保留输入。标题不要求装饰图标。
- 分区按“应用、内容”组织，默认打开外观。宽屏使用官方 NavigationDrawer；手机使用连接式列表。

分区切换更新当前设置地址而不清除进入前的路由；窄屏通过真实列表／分区页面栈逐层返回，页头与系统返回共用该路径。宽屏的分区属于同一设置工作区，返回直接退出设置。选中分区内容在单双栏切换时保留同一个子树；桌面已经显示的默认分区在缩窄后也继续显示详情。短横屏顶栏采用共享紧凑高度，正文避让侧边与底部安全区。

窄屏分区列表在进入内容后返回时保留原滚动位置，避免大字号或短窗口下重新从顶部寻找刚才的分区；该位置只随当前设置页面保留。

设置工作区保留配置响应，返回目录再进入其他分区不重复加载。更换 API 连接后重新读取配置，单项保存继续直接合并 PUT 响应。

推送凭证与权限使用可折叠的直接表单：平台、凭证、超级管理员、白名单和黑名单，再保存。移除 Stepper 和未接入保存的独立 Telegram 管理员输入框；实际管理员仍通过原有 `*_admin_ids` 配置保存。Bot Token 输入遮蔽显示。停止的 Telegram 使用普通状态文字，按运行状态显示启动或停止/重启，不将“未运行”猜成“未配置”；QQ 连接失败不伪装为在线，状态读取失败可重试。桌面设置表面使用 Material，避免遮挡列表水波纹。推送目标空态与读取失败不套卡片，失败可重试。

外观的“跟随系统、浅色、深色”使用分段按钮，选择立即应用；窄空间或大字号时按实际标签宽度调整排列。应用名、真实版本与开源许可组成简洁的关于区域。

## 视觉语义

- 分区与内容依靠单一表面色差表达层级；右侧仅保留外侧圆角。相关设置使用连接式列表组成整体轮廓，弹层保持独立操作语义。
- 设置组复用 AppSettingGroup（M3EList）：使用组件默认外圆角 16dp、内部圆角 4dp、行间距 2dp。每行保留自己的 Material 和语义边界，支持独立水波纹、焦点与开关。普通开关与标签同行，长操作独占一行，高级参数使用标准展开控件。
- 具体业务状态使用 `ColorScheme` 语义色，设置 Shell 不固定浅色或深色值。
- 普通设置工具页使用标准 Material 3 tonal AppBar；二维码区域保留黑白对比，不把毛玻璃或品牌固定色当作通用状态语义。

## 承担职责

- 全局、低频、用户可控的配置。
- 能力状态和真实测试入口。

## 不承担职责

- 不展示完整运行历史或复杂收藏同步工作流。
- 不管理外部平台账号对象或登录会话。
- 不暴露后端尚未实现的策略占位。
- 不把自动化领域操作复制到设置中。

### 推送目标表单（2026-09-13）

添加／编辑目标是少量字段的一次性操作，使用随内容收缩的自适应表单弹窗，取消手机强制全屏和固定高度。类型、标识、显示名称与启用状态直接排列，取消图标底座、开关背景板和按钮局部形状；输入名称独立显示，长标签与提示在大字号下可换行，控件仍提供完整语义名称。

敏感内容分流默认折叠，已配置备用目标时展开；低频字段不挤占首屏。展开遵循共享时序和减少动画设置，开关反馈与折叠区域沿圆角裁切。短横屏或键盘压缩后共用同一滚动表单，操作区可随内容滚动到达。类型与目标 ID 的规范化、创建／修改回调沿用原逻辑。

目标列表直接显示同步／新增入口和数量，不再重复页面标题。每项目标按名称与类型、整体启用、用途选择组织；长名称可换行，整体开关的语义包含所属目标。巡逻监听与分发推送使用可独立选择、随宽度换行的主题控件，保留等宽状态图标，避免选择状态改变后发生换行跳动。移除缩小开关、用途选项的额外边框、平台图标底座及重复分界线，目标之间只保留一条分隔。

内容处理的媒体归档组直接呈现归档总开关，开启后显示图片／视频开关。质量与数量限制在原页展开，使用共享时序并尊重减少动画设置；展开入口与开关反馈保持圆角。数值字段名称与说明独立显示并允许换行，普通宽屏并列、窄屏或大字号单列，表单限制阅读宽度。数量和字节单位、零值含义及原有提交路径保留。

通知分区的定期摘要开关、周期选择和立即生成依次排列；周期菜单复用共享圆角菜单，宽屏与生成操作并列，小屏／大字号换行。

机器人转存收藏开关位于来源的连接账号列表；通知分区不重复提供账号管理入口。单字段设置写入后使用 PUT 响应更新界面，不再全量重新读取配置。

连接与模型配置共用的展开设置使用标准 Material 展开组件：向下箭头表示原页展开，标题反馈与外框保持圆角，内容沿页面纵向让位。展开内容首次打开才挂载，打开后收起保留输入状态，同时禁止隐藏字段获得焦点；减少动画模式直接呈现终态。字段控制器、配置提交与连通性操作继续由具体页面负责。

连接分区直接排列服务器地址、访问密钥、连接测试和网络代理，不为单个代理选项另设分组标题。测试连接使用操作按钮，避免导航箭头误导；每个单值编辑区复用主题输入样式，并明确保存地址／更新密钥／保存代理。编辑区持有并释放输入控制器，主题变化和当前页面内的滚动不会覆盖未保存草稿；尚未编辑的字段可跟随已保存值更新。离开页面时释放编辑状态。

连接单值编辑与模型、存储等设置共同使用 `SettingsEditorDraft` 管理上述生命周期，不再维护单值编辑器专用状态类。各配置的字段、默认值、空密钥处理及保存回调仍明确留在所属页面。

AI 模型配置按通用模型（文字与图像）、向量和摘要连续排列，诊断随后折叠；使用同一展开样式，移除模型间的重复分隔。字段名称和说明在输入框外显示并允许换行，输入框沿用主题形状，表单限宽。向量配置先展示参数与保存，再展示索引状态。三类编辑区持有输入控制器，主题重建不覆盖未保存草稿；原有模型默认值、空密钥不更新与保存路径保留。

模型名称、维度、密钥配置状态与平台连接状态按独立信息项换行排布，不用点号拼接；许可页的应用名与版本分层呈现。

能力诊断的名称与状态可换行，说明、问题和最近测试结果各自占完整内容宽度，测试操作单独显示；空态与读取失败不套重复设置组。索引状态使用普通统计文字，去除外框和胶囊嵌套；最近失败的标题、原因与重试次数分别展示，不再两行截断。最近尝试时间按本地日期与时间显示，加载失败复用统一错误提示并提供重新加载。展开设置在当前列表中滚出缓存后仍保持展开；收起后的表单草稿继续由各编辑区负责。

来源新建／编辑采用共享自适应短表单：普通高度正文滚动、操作固定，短屏操作进入滚动内容；移除仅此处使用的旧表面封装。字段名称外置换行，类型和同步频率复用共享圆角菜单。类型只在新建时选择，编辑时只读展示，与后端不可修改类型的 contract 一致；已有非预设同步间隔保留并按时长排序显示。提交中阻止重复操作及返回，成功后关闭，失败保留草稿并在表单中提示。

来源列表按名称与类型／同步间隔、启用与立即同步操作分层，名称完整换行，说明按完整片段换行，禁用来源的同步按钮不可用。添加入口归属来源标题，空态和读取失败不重复套框；来源与筛选设置共用阅读宽度。筛选开关直接排列，兴趣偏好在原页展开且持有草稿；评分阈值拖动时本地显示、松手后保存一次，等待期间禁用滑块。保留时间与清理方式在宽屏并列、窄屏或大字号下纵向排列，菜单保留当前非预设天数，说明完整显示。

存储数量与体积输入持有独立草稿，主题重建和展开收起不覆盖未保存值；质量与限制入口复用共享展开样式。草稿只在当前页面内保留，离开页面时释放控制器，配置键及提交规则不变。

存储压缩质量与 AI 评分阈值共用滑块交互：拖动时立即显示候选值，松手后保存一次，等待期间禁止再次操作；保存失败提示原因并恢复已保存值，成功后等待配置刷新时保留当前显示。压缩质量范围、步长及配置键保持原约定。

许可列表按组件名排列，仅在包含多份许可时显示份数，移除逐项重复箭头；应用版本只占一行辅助信息。正文采用限宽单列，完整组件名随正文滚动，多份许可仅用小标题分组，保留注册许可的段落文本、顺序、居中与缩进。正文支持文字选择；列表到正文使用标准页面过渡，返回保留列表位置。手机与宽屏采用同一阅读层级，不再使用错位的多重主从面板。

分区列表的图标、名称与方向箭头居中对齐，不另加重复说明。

窄屏设置分区通过 `OriginMaterialPage` 从点击行展开，返回时收回该行；列表在分区下方保留状态。单双栏切换复用当前分区子树，不清空草稿。根弹层与许可阅读覆盖整个设置工作区，返回先处理根层。

归档数量只接受非负整数，视频容量使用 MB 输入并转换为后端字节值。空值或非法输入不再隐式保存为 0；字段提供明确保存动作，提交时禁用重复操作，失败保留草稿并在原位提示。

代理、平台凭据、媒体归档及模型编辑器读取失败时显示原位重试，不再静默变空白。模型与平台凭据保存过程中禁用重复提交，失败提示留在操作旁，输入草稿继续保留。

模型保存期间显示“保存中”并禁止重复提交，失败留在原处提示重试，成功明确反馈。文字与图像只保存一份通用模型配置。

通用、摘要和向量配置复用输入及保存反馈，仍保留各用途独有的地址、API 版本和维度字段；已保存密钥留空表示不修改。向量维度在提交前校验，失败不先写入部分配置。

订阅来源页只负责来源对象管理，支持名称搜索、RSS / Telegram 类型和启停状态组合筛选；兴趣偏好、评分与保留策略统一归入设置的“内容筛选”。

内容处理按“自动处理”“内容整理”“媒体归档”分组，直接显示开关，不重复显示“已关闭”、零任务统计和通往同一配置的按钮；运行诊断留在模型诊断和任务详情。AI 模型将通用、向量和摘要配置合并为一个关联列表；服务器地址与访问密钥并列在连接组。界面复用既有保存反馈和草稿状态。

单选设置复用 AppFilterMenu：当前值与候选项在同一个原位展开表面内，候选列表不重复当前值。组件基于 Material MenuAnchor，保留键盘导航、Esc 和点击外部关闭，尊重减少动画。消息账号、内容平台、摘要、机器人、归档与筛选设置按任务使用一致的分组行；展开行和状态层服从外层分组形状。
