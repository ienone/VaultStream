# 来源与账号

## 页面与操作

横屏从首帧固定左侧列表或功能选项与右侧详情，加载时在对应栏显示骨架。账号默认打开 Telegram，收藏同步可分别选择平台或进入全部平台的同步设置。窄屏保留列表到详情的导航。

`/accounts` 按内容平台和聊天账号列出连接。账号行显示是否已保存凭据及已确认的登录失效状态。连接、更新登录、检查登录状态和清除登录在此操作，哔哩哔哩另支持手动输入 Cookie。平台网络不可用时保留已有连接。

账号列表的分组标题与项目文字对齐，各导航行独立裁切选中背景和点击反馈。账号详情采用统一的水平 16dp、垂直 24dp 留白。

Telegram 和 QQ 的机器人设置在对应账号详情中。连接地址、凭证和权限按需展开。Telegram 可单独修改管理员、允许和禁止访问的用户；QQ 设置助手开关、管理员及允许的群组。Telegram 的个人账号连接独立于 Bot。

`/sources/sync` 集中展示平台、同步设置和近期结果。`/sources/sync?platform=平台名` 打开该平台的自动同步开关、读取频率、预览、执行和历史。Telegram 使用独立的已保存消息和频道同步选项。任务可从历史返回对应运行详情。

订阅搜索与类型、状态筛选同时决定左侧列表和右侧默认详情；没有匹配结果时两栏显示对应空态，搜索框可直接清空。

订阅和群组监听分别位于 `/sources` 和 `/sources/chats`。服务器地址、VaultStream API 密钥与代理位于设置。
