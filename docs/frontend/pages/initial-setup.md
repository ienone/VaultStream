# 初始连接与配置向导

## 文档状态

active

## 当前入口

- `/connect`：`frontend/lib/features/auth/presentation/connect_page.dart`。
- `/onboarding`：`frontend/lib/features/auth/presentation/onboarding_page.dart`。

连接页接收服务器地址和访问密钥，验证成功后由已有认证状态驱动路由进入应用。配置向导按功能与 AI、通知、账户、完成四步组织可选设置；完成概览可返回对应配置位置。正式进入应用后的日常维护由设置和账号中心承担。

## 布局与交互

向导使用可横向滚动的步骤标签，当前步骤有明确选中状态。步骤、表单、错误提示和下一步动作属于同一纵向滚动区域；空间充足时导航位于底部，短屏与键盘压缩时随内容滚动，不用固定按钮底板遮住表单。切换步骤释放输入焦点并回到新步骤顶部，已有输入由页面持有的控制器保留。提交期间步骤入口不接收指针和键盘焦点。

功能与通知采用限宽的连续单列表单，避免展开一项后并排网格留下空洞。账号概览可多列展示，列数考虑字号；窄卡片的扫码操作移到账号状态下方。模型与维度输入在空间不足时纵排。完成概览为可直接修改的阅读列表，不额外套卡片和图标底板。

连接页的标题和输入沿同一阅读列排列，短高度减少装饰与顶部留白，表单限宽且可整体滚动。服务器地址使用键盘“下一项”，密钥使用“完成”触发连接；提交先释放输入焦点，加载按钮明确显示连接中，失败提示可由辅助技术获知。认证验证与保存继续沿用已有 LocalSettings 路径。

功能与通知的配置开关共用沿顶边裁切的展开组件。收起完成前保留正文，快速反向从当前位置继续；隐藏内容不接受焦点、点击或读屏导航，输入组件在关闭后仍保留状态。减少动画时直接到位，包括动画进行期间开启该设置。首个输入上方留白容纳浮动标签。
