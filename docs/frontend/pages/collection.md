# 收藏库页面

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/collection/collection_page.dart`
- 路由：`/collection`

## 用户任务与当前界面

用户可以浏览存档卡片、通过顶栏胶囊搜索条使用关键词或语义搜索、按平台/状态/标签/作者/日期筛选，并进入选择模式执行批量维护。列表支持刷新、分页加载以及新增链接。

卡片主要展示代表媒体、来源、作者、标题、摘要、标签和少量状态。加载骨架、空库、查询无结果、请求失败和分页失败应有可区分反馈。

新增内容使用底部操作面；批量删除或影响范围较大的修改需要二次确认。

## 自适应行为

- 内容列数随可用宽度变化，但保持卡片可读宽度。
- 选择模式在所有断点使用一致的选中状态和操作语义。
- 搜索、筛选和新增入口在窄屏避免同时挤占标题空间。

## 承担职责

- 收藏内容浏览、搜索、筛选和批量管理。
- 作为内容详情的稳定入口。
- 呈现存档与后处理的必要状态，不展示完整后台诊断。

## 不承担职责

- 不承担平台账号、发现候选审核或分发规则管理。
- 不在列表卡片中挂载详情业务内容；卡片到详情只共享一个按内容 ID 配对的不透明容器，深链接或减少动效时降级为普通页面转场。

## API 关联

- 领域：`../../backend/api/contents-search-media.md`
- 后台变化：解析、媒体归档和语义索引会更新卡片状态。

## 当前问题

本地归档缩略图会在进入图片组件前统一映射为受鉴权媒体 URL，避免详情图片可用但卡片封面裂图。后续结构与转场目标见前端 IA plan。
