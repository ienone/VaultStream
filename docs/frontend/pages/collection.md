## 文档状态

active

## 当前代码

## 用户任务与当前界面

用户先在全宽卡片区浏览存档，打开内容后进入列表—阅读工作区。顶栏搜索条直接提交当前列表查询，可按平台/状态/标签/作者/日期筛选，可进入选择模式执行批量维护。条目侧滑操作提供“推送”“选择”和“删除”，批量面也可推送到所选目标，复用推送表单及发送结果。关键词和空查询支持分页，语义查询使用 top_k；两者共用 `/search/unified`、请求类型、筛选表单与卡片解析。搜索框只负责当前列表查询，清除查询保留其他筛选。搜索输入最大宽度 640dp，筛选紧随输入框，工具栏与筛选摘要均保留内边距，避免贴住工作区圆角。新增内容从动态或收藏库页头的保存入口进入。

未选中内容时，卡片区占满工作区，不预留空阅读器或拖柄。宽屏点击卡片更新 `/collection?item=ID`，左侧变为单列列表，右侧复用 ContentDetailPage；列表和正文独立滚动。关闭阅读器恢复卡片浏览，两种布局复用同一个滚动控制器，并以视口顶部内容为锚点换算滚动位置。拖柄支持拖动、键盘左右键微调、Home/双击复位，列表宽度在 280–480dp 内持久保存；可用空间更小时临时收窄，不覆盖保存值。专注阅读隐藏列表，重新显示时保留同一个阅读器和滚动位置。独立 `/collection/:id` 继续用于外部深链和跨页面结果，不创建另一套详情业务。

列表和阅读器各自拥有同一顶部水平带内的顶栏，不在阅读器上方再叠放横跨工作区的收藏顶栏。搜索、筛选摘要与批量操作只属于列表列；长按保留当前阅读器与 URL，搜索和筛选区不因选择模式消失；专注阅读时随列表一起隐藏。顶栏使用不透明页面表面，列表滚动和筛选变化不遮挡或下推阅读器操作。单双栏判断由工作区统一负责，避免列表顶栏扣除高度后再次触发另一套断点。

拖动从起始宽度与指针全局位移计算当前宽度，拖柄移动或同帧多次指针事件不改变计算基准；拖动期间不插值、不写入持久偏好，结束时才保存。触及上下限后反向拖动仍按同一起点定位。

收藏预览显示真实作者头像、作者与平台、日期、标题及正文摘录。作者与平台分行，日期独立对齐，不用中点拼接信息。只展示实际缩略图，头像不充当正文封面；没有标题时直接展示正文预览，不重复生成“无标题”卡片。语义搜索优先展示实际命中的原文片段，不展示算法标签或分数。浏览量、点赞与完整标签留在详情。加载骨架、空库、查询无结果、请求失败和分页失败应有可区分反馈。

卡片不再常驻“显示操作”按钮；触摸侧滑、桌面右键与键盘 Shift+F10 可展开既有推送、选择与删除操作，辅助技术保留相同动作。长按选择和阅读工作区行为不变。

封面候选全部加载失败时，卡片收起灰色图片占位，将文字移到内容区顶部并显示“重试图片”。整卡高度保持不变，避免列表与阅读切换的滚动锚点跳动；详情媒体仍保留原有失败说明和重试。

宽卡片与紧凑列表采用相同来源显示条件：没有 HTTP(S) 来源的文本和文件捕获不显示“网页”平台标签。

接近列表底部时继续自动分页；有下一页时，底部同时提供“加载更多”，避免宽屏首批卡片不足一屏、无法触发滚动的情况。请求期间显示进度，不保留可重复点击的加载按钮。

新增内容使用与 Root Shell“保存内容”相同的统一操作面，可选择链接、原始文本或本地文件。应用内粘贴和系统分享经过同一组件与内容写控制层，只保留来源上下文差异；纯文本系统分享不再被错误要求提供 URL。原始文本直接保存正文并进入收藏库，不显示无效的“原文”外链。同一次分享的多个文件保存为一个内容对象；多张图片形成图集，视频、音频和文档保留各自媒体身份与签名原件入口，但当前不声称已完成 OCR 或转写。链接成功后提示“后台将继续解析”并提供内容详情入口；内容已保存但解析队列暂不可用时显示明确的待处理提示，而不是误报为完全失败。批量删除或影响范围较大的修改需要二次确认。

收藏库的查询、平台筛选和列表状态在切换到动态或自动化后保持。显式“清除筛选”会同时清除 provider 与搜索输入框，避免显示文本和实际查询范围分离。

## 自适应行为

- 浏览时恢复 1–4 列卡片网格，按每列约 300dp（随字号缩放）的宽度决定列数，当前约 1414dp 桌面窗口显示四列；打开详情变为单列，关闭恢复网格。两种布局共用按内容 ID 标识的 SliverGrid 懒加载树，加载骨架采用相同目标列数。
- 内容区统一圆角裁切，条目和筛选栏目通过主题表面色阶区分，不叠加分界线；列表与阅读器使用不同层级底色。悬停使用中性色调，当前阅读项与批量选中项使用强调色调，多选另有勾选标记，不通过外框改变卡片轮廓。
- 打开内容后，按工作区可用宽度、字号与高度判断是否可并排阅读，左侧始终为单列。窄屏、短横屏和大字号空间不足时，点击条目 push 标准内容详情页面，背景列表不改变宽度或重排，返回恢复浏览区；不只按横竖屏判断，也不叠放收藏顶栏与阅读器顶栏。
- 单列始终使用标题左、缩略图右的紧凑布局，标题最多两行，缩略图 72–88dp 宽、64dp 高；极窄或大字号导致正文空间不足时省略缩略图，不改成大图置顶。缺少封面时文字使用整行。宽卡片预览可按空间使用上图下文。
- 作者与平台各占一行并截断长文本，选择指示器留在元信息行末，不挤占整条正文宽度。悬停与选中背景均由完整条目的同一表面绘制，不给媒体和文字叠加遮色。
- 选择模式在所有断点使用一致的选中状态和操作语义。普通/选择模式顶栏在紧凑高度下均缩短至 48dp。
- 搜索、筛选和新增入口在窄屏避免同时挤占标题空间。
- 捕获面在 Expanded 及以上使用限宽 dialog；手机、Medium 和短横屏使用可滚动 bottom sheet，避让键盘且不依赖固定高度容纳全部字段。

## 承担职责

- 收藏内容浏览、搜索、筛选和批量管理。
- 作为内容详情的稳定入口。
- 呈现存档与后处理的必要状态，不展示完整后台诊断。

## 不承担职责

- 不承担平台账号、发现候选审核或分发规则管理。
- 不在列表卡片中挂载详情业务内容。阅读模式内收折或跨断点调整保留同一阅读器，不通过 Hero 重建阅读器。

## 筛选面与日期选择（2026-09-12）

宽屏筛选采用保留边距的圆角侧面板，由右侧进入并原路退出；手机保留底部弹层。筛选不重复显示标题与关闭按钮，遮罩点击和返回可取消草稿，底部保留重置与应用。常规高度下动作固定在底部，短横屏或键盘压缩后动作进入表单滚动区；可用高度不足 180dp 时标题也随表单滚动，避免固定标题挤掉全部内容。筛选仍先编辑草稿，只有应用才改变收藏列表。

处理状态使用四项多选分段按钮，保留 OR 语义，全部取消表示不限。内容平台与标签使用不带搜索框的勾选菜单，选中项在字段内显示，可单项移除或清除。作者保留独立输入，候选不再平铺占满表单。菜单与条件均为草稿，只有“应用筛选”提交。

保存日期的“不限、今天、7 天、30 天”使用分段按钮；自选范围使用官方 DateRangePickerDialog，在最大 560×640dp 的圆角弹窗中提供日历与日期输入。选择器按自身可用空间布局，缩放窗口保留日期草稿，取消不改变筛选。查询终止日仍包含该日完整时间。

有查询时显示关键词/语义切换，语义模式提供 1–100 条结果上限。少量选项按实际文字宽度决定横排或竖排，短横屏的确认操作随内容滚动。

## 批量操作与反馈（2026-09-12）

批量动作直接位于列表底部的横向操作栏，数量与退出在列表顶栏；标签编辑和删除确认使用根导航弹窗，避免播放器遮挡。常规动作与永久删除沿用主题语义。标签编辑明确说明替换全部标签，留空对应清空；中文逗号和换行均可分隔并去重。删除确认说明内容与独占归档文件的影响。

操作复用 ContentActions 的鉴权、错误提示、刷新和受理结果。提交期间保留进度并禁用重复操作、选择变更和弹层关闭；完成后显示结果反馈。部分失败只保留失败项选中，已确认成功或受理的项不会再次参与重试；重新解析的受理不冒充后台完成。关闭编辑或确认弹窗保留选择，取消最后一项仍保持批量模式，退出选择才结束。

2026-09-13 已生效筛选摘要的逐项移除也改用 Chip，明确标注“移除筛选 …”；长查询／条件限制标签宽度并提供完整文本提示，保留横向滚动及原有清除 provider 逻辑。

宽屏模板选择与批量操作主弹窗复用共享返回预览，撤回保持当前操作面，提交返回来源。手机底部弹层继续由原有路由承载，本次宽屏接入不外推其原生手势验证。

### 2026-09-30 选择与阅读衔接

选择模式在列表底部直接提供“推送”“标签”，重新解析、敏感标记和删除收纳到标准 MenuAnchor 菜单，删除与普通维护操作分隔。数量和退出位于顶部栏，切换工具栏时尊重减少动画。保留提交禁用、进度、标签编辑和删除确认，退出选择不关闭阅读器。

多选不展示空复选框；已选项在元信息行右侧保留小勾，单列相邻选中项以无缝背景连接，只保留首尾圆角。鼠标在多选模式按住划过选择连续范围；触屏长按后拖动选择，从已选项起拖则取消该范围。拖回时恢复范围外原选择，靠近列表上下边缘自动滚动；手势期间不打开内容，提交批量操作期间禁止改变选区。

收藏和动态共用列表—阅读工作区。路由立即更新，列表在同一滚动树内随分栏调整宽度，不复制卡片或详情到浮层。

列表与阅读器直接以底色交接，调整宽度的命中区叠放在边界上，不占独立竖带。宽屏阅读器左侧上下圆角一致，窄屏使用完整页面；批量操作栏四周保持 8dp 留白与完整圆角。参考 Animeko 搜索分栏的面板和内容留白职责，不照搬其 Kotlin 实现。

选择模式下整张卡片及右侧勾选区域共用同一点击动作；选中后通过色调背景、边框和勾选标记立即反馈。普通浏览和选择模式的按压反馈均绘制在封面上方，宽卡片、紧凑列表和长按进入选择保持一致。

重新解析开始、正文落库及后处理完成后，卡片、正文和处理阶段自动重读；断线重连、App 回到前台也会补读。更新保留筛选、已加载页数与阅读位置。移除页头重复刷新按钮，手动刷新保留在列表下拉动作，加载失败仍在原位置提供重试。

打开与关闭详情时，卡片网格与单列的位置、宽高和封面布局跟随工作区实际宽度插值，正文按目标宽度排版。卡片以内容 ID 保持身份，不按整行重建、不逐项启动动画。端点行高按封面、标题、状态与命中片段计算，动画只更新可见条目的几何位置。动态继续保持原有单列信息流。拖动、窗口调整和减少动画直接采用目标布局。

已删除旧坐标登记、共享飞行层与逐项位移补偿。新进入视口的条目使用同一份布局进度，不依赖是否曾经出现在阅读模式中。

工作区保留一个阅读器实例，关闭后隐藏并暂停其动画；重新打开复用它，切换内容重置目录、图片选择与阅读滚动。阅读器使用独立绘制边界，列表分栏动画不重复绘制正文。

封面解码按 600×160dp 目标区域及屏幕像素比计算 cover 所需比例，保持原始宽高比且不放大原图。浏览与紧凑模式复用同一解码尺寸；不能仅按高度缩小，否则极长竖图的宽度会退化到几像素。

本地边界验证使用独立数据库与实际保存接口构建千条内容，覆盖 1×1、8000×200、200×8000、4096×3072、透明图、损坏图、500 字符标题及 20 万字符正文。已走通桌面、320px 竖屏和 844×390 横屏阅读、目录定位、图集连续切换、分页末尾和返回。

图片连续开关的修复包括：隔离布局进度的订阅范围，避免卡片整树逐帧更新；比较列表内容而非 Freezed 只读包装的身份，避免每次打开详情清空卡片缓存；详情加载状态共用页面骨架；按显示尺寸解码图片；Web 使用 Wasm 构建。Chrome 本地 release 五轮连续打开、切换和关闭采样，收藏最长动画回调约 41ms，动态约 26ms，没有超过 50ms；滚动后打开和全屏图集另行通过实际操作检查。这是主线程回调采样，不是屏幕呈现帧率保证。

2026-10-18：手机详情入口使用 `/collection/:id` 根页面和平台标准转场，恢复路由级预测性返回条件；宽屏仍使用 query 选中项与分栏形变。宽屏已打开的阅读工作区缩窄时立即切换完整阅读布局，不执行列表宽度归零的动画。

多选取消最后一项时退出；筛选或实时刷新移除已选内容后，选择集合同步收敛到当前结果，避免操作栏保留已不存在的对象。批量操作期间保持原选择，由操作结果统一处理成功与失败项。

收藏网格按封面、实际标题和摘要行数计算条目高度，将下一项放入当前最短列，避免短条目被同排图片撑高。网格与阅读单列共用条目身份和布局进度，切换时保持滚动锚点。

窄屏收藏条目采用标题与右侧缩略图并列，来源和时间使用次级文字；桌面四列网格和详情布局变形保留。手机左滑显露推送、选择和删除按钮；桌面行末入口展开同一操作区，手机不重复显示入口图标。侧滑实现与规则列表共用 SwipeActionReveal，多选时禁用，点击其他区域收回。筛选弹层按实际内容收缩，并在最大高度内滚动。

### 收藏侧滑操作（2026-10-19）

内容区由整体圆角容器承载；普通条目、当前阅读项和多选态分别使用主题表面色与选择色。原更多菜单合并到侧滑操作区，拖动或点击桌面行末展开入口均可显示推送、选择、删除；删除沿用确认，不以整段滑动直接执行。桌面保留网格和键盘可达入口。

侧滑反馈：拖动直接跟随手指；释放后使用 AppMotion.standard / standardCurve 吸附或收回；操作背景从收拢的圆润形状展开，图标同步位移、缩放和小角度归位。点击立即反馈并收回操作区。无声音或触觉，减少动画时取消背景及图标装饰变换并即时吸附，保留直接拖动与全部按钮。每行使用一个可中断控制器，只更新操作区域，正文作为稳定子树复用。

收藏工作区使用 `SharedLayoutTransition` 提供同一份插值宽度，列表排布、阅读区与分栏拖柄同步变化；尺寸变化和手动拖动直接使用当前布局值。媒体共享转场由共享元素组件管理可见性，列表与阅读器不再各自覆盖 Hero 开关。

平台与标签使用同一勾选菜单，处理状态使用分段按钮；仅应用后更新结果。
搜索模式、检索范围和语义结果数量归入可展开的“搜索选项”，折叠时显示当前配置摘要。
