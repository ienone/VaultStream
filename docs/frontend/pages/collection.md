# 收藏库页面

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/collection/collection_page.dart`
- 路由：`/collection`

## 用户任务与当前界面

用户可以浏览存档卡片、通过顶栏胶囊搜索条使用关键词或语义搜索、按平台/状态/标签/作者/日期筛选，并进入选择模式执行批量维护。列表支持刷新与分页加载，新增内容统一从全局保存入口进入。

收藏预览按来源、类型与时间、标题及必要状态组织。只展示实际缩略图，没有封面时不生成大图标占位；语义搜索可展示实际命中的原文片段，不展示算法标签或分数。浏览量、点赞与完整标签留在详情。解析结果包含作者头像时，头像应出现在卡片来源元信息中；没有头像时不额外占位，避免压缩标题和统计空间。无封面且模板以作者身份为主要视觉时，可把头像作为代表媒体放大展示。加载骨架、空库、查询无结果、请求失败和分页失败应有可区分反馈。

新增内容使用与 Root Shell“保存内容”相同的统一操作面，可选择链接、原始文本或本地文件。应用内粘贴和系统分享经过同一组件与内容写控制层，只保留来源上下文差异；纯文本系统分享不再被错误要求提供 URL。原始文本直接保存正文并进入收藏库，不显示无效的“原文”外链。同一次分享的多个文件保存为一个内容对象；多张图片形成图集，视频、音频和文档保留各自媒体身份与签名原件入口，但当前不声称已完成 OCR 或转写。链接成功后提示“后台将继续解析”并提供内容详情入口；内容已保存但解析队列暂不可用时显示明确的待处理提示，而不是误报为完全失败。批量删除或影响范围较大的修改需要二次确认。

收藏库的查询、平台筛选和列表状态在切换到动态或自动化后保持。显式“清除筛选”会同时清除 provider 与搜索输入框，避免显示文本和实际查询范围分离。

## 自适应行为

- 列数按扣除导航后的可用宽度与系统字号决定；窄屏自然高度单列，足够宽的手机横屏、平板和桌面按行组织多列。大字号自动减少列数。来源元信息使用完整卡片宽度，头像与作者作为一组换行；正文空间足够时使用右侧紧凑缩略图，窄卡片或大字号导致文字过窄时，图片放在正文上方并限制高度。缺少封面时文字使用整行，不预留媒体区。骨架沿用相同列数与紧凑卡片高度，不再套用旧的大封面比例。
- 混合内容浏览按每个卡片槽位约400dp的阅读空间计算，最多四列；不随窗口类别直接升列，避免缩略图把中文标题挤成窄条。约1200dp可用区域采用三列，加载骨架与实际内容共用该规则。
- 来源元信息允许换行，避免两倍字体或长作者名挤出卡片。选择指示器占用独立位置，不压住标题和缩略图。
- 选择模式在所有断点使用一致的选中状态和操作语义。普通/选择模式顶栏在紧凑高度下均缩短至 48dp。
- 搜索、筛选和新增入口在窄屏避免同时挤占标题空间。
- 捕获面在 Expanded 及以上使用限宽 dialog；手机、Medium 和短横屏使用可滚动 bottom sheet，避让键盘且不依赖固定高度容纳全部字段。

## 承担职责

- 收藏内容浏览、搜索、筛选和批量管理。
- 作为内容详情的稳定入口。
- 呈现存档与后处理的必要状态，不展示完整后台诊断。

## 不承担职责

- 不承担平台账号、发现候选审核或分发规则管理。
- 不在列表卡片中挂载详情业务内容；卡片到详情只共享一个按内容 ID 配对的不透明容器，深链接或减少动效时降级为普通页面转场。

## 当前问题

缩略图直接使用后端媒体资产候选，不在前端重写存储地址。后续结构与转场目标见前端 IA plan。

页头在 medium 及以上直接显示全局工具；收藏搜索在 large 以下独立于工具栏，避免账号、消息等按钮展开后挤窄输入框。large 及以上继续在标题旁显示搜索。

大字号按折算后的可用宽度将搜索移到工具栏下方，入口不再固定为 40–44dp 高。输入集中在展开的搜索面中：窄屏、大字号空间不足或短横屏使用全屏搜索，宽屏保留锚定入口的限宽浮层并随内容收紧高度。搜索方式只显示名称和简短说明，查询词留在输入框，历史记录另以“最近搜索”分组。取消恢复入口中的已生效查询，提交保留新查询，避免草稿与筛选摘要不一致。

全屏搜索由根 Navigator 的标准页面承接，覆盖底下主导航与播放器；页面持有独立输入草稿，旋转、字号与键盘变化保留同一页，并重新计算阅读宽度。关闭只取消草稿，选择搜索方式或提交后才把查询交回收藏库。返回采用主题平台过渡，键盘 Escape 可取消；宽屏锚定浮层与搜索页复用同一组选项和历史内容，不各自维护搜索业务。

## 筛选面与日期选择（2026-09-12）

宽屏筛选采用保留边距的圆角侧面板，由右侧进入并原路退出；手机保留底部弹层。标题区提供独立关闭，底部只保留重置与应用。常规高度下动作固定在底部，短横屏或键盘压缩后动作进入表单滚动区；可用高度不足 180dp 时标题也随表单滚动，避免固定标题挤掉全部内容。筛选仍先编辑草稿，只有应用才改变收藏列表。

2026-09-13 收敛筛选表单内部层级：分组使用中性色标题和间距，移除标题下分界线、标签建议的额外背景板及重复的作者标题。平台与状态使用支持多选的 FilterChip，选中增加勾选标记；选项与日期动作沿用主题圆角。标签建议直接在输入下展开，已选标签限长并提供完整名称提示及明确的移除按钮。建议从当前输入与标签加载结果直接计算，加载失败提供原位置重试。

只提供删除操作的已选标签使用 Chip，避免当前 Flutter InputChip 在 Web 将其父节点标为禁用，连带影响删除按钮操作。语义结果数量与接口一致为 1–100，显示“最多显示 N 条结果”，修复载入 1–4 时滑块断言失败。后端查询与应用／取消草稿边界不变。

日期选择移除额外的从零缩放动画，由单一路由控制进入/退出，并尊重系统减少动画。日期弹层复用共享返回预览，拖动撤回保持当前选择，提交返回只关闭日期层；未确认的日期不覆盖底层筛选草稿。短横屏优先显示日期输入且适当加宽，普通高度使用日历；选择后展示完整起止日期。“今天”与其他快捷范围按起止日期共同判断，避免自定义范围被误标为快捷选择。

日期层打开后，窗口尺寸变化保留同一选择器、输入模式和草稿。键盘空间只由当前顶层弹窗消费，底层筛选不重复缩小；高度不足时整块日期内容可滚动，外层 Material 统一裁切圆角，内部按实际内容尺寸布局，保证日历日期可见而不只剩标题。键盘或尺寸变化后将聚焦输入框连同浮动标签滚入可见区域；确认/取消可通过滚动到达。

## 批量操作与反馈（2026-09-12）

宽屏批量操作使用限宽对话框，手机及短横屏使用根导航上的可滚动底部弹层，避免播放器悬浮条压住操作。顶部显示选中数量和独立关闭，常规动作与永久删除分组，颜色沿用主题。标签编辑明确说明替换全部标签，留空对应清空；中文逗号和换行均可分隔并去重。删除确认说明内容与独占归档文件的影响。

操作复用 ContentActions 的鉴权、错误提示、刷新和受理结果。提交期间保留进度并禁用重复操作、选择变更和弹层关闭；完成后在原弹层显示结果。部分失败只保留失败项选中，已确认成功或受理的项不会再次参与重试；重新解析的受理不冒充后台完成。关闭弹层保留选择，取消选择明确退出批量模式。

2026-09-13 已生效筛选摘要的逐项移除也改用 Chip，明确标注“移除筛选 …”；长查询／条件限制标签宽度并提供完整文本提示，保留横向滚动及原有清除 provider 逻辑。

宽屏模板选择与批量操作主弹窗复用共享返回预览，撤回保持当前操作面，提交返回来源。手机底部弹层继续由原有路由承载，本次宽屏接入不外推其原生手势验证。
