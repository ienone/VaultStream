# 任务结果页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/dashboard/task_result_page.dart`
- 路由：`/tasks/:runId`

## 用户任务与当前界面

用户可以通过稳定 `runId` 查看持久化后台运行的业务标题、状态、摘要、结果 section、关联对象、时间和下一步入口。页面支持加载失败重试和手动刷新；原始 metadata/result 默认折叠到“技术详情”。前端严格消费后端 `presentation`，不再从任意字段拼展示摘要或目标路由。

页面不提供通用业务重试，因为不同任务的权限、参数和副作用不同。收藏同步使用专用 renderer 复用既有 run、单项和批量 retry contract；服务端领域策略仍是权威边界。其他任务当前只提供安全导航动作。

收藏同步最近运行和历史 highlight 均跳转本页，不再打开第二套运行详情弹窗。

## 自适应行为

- Compact/手机横屏使用单列，基础字段允许标签和值换行，不依赖固定横向表格。
- Expanded 及以上且高度足够时使用业务结果—运行信息双栏；短高度仍退回单列。
- 大型 payload 保持可滚动、可选择，不撑破页面宽度。
- 后续任务类型 renderer 在宽屏可以增加摘要/原始数据分栏，窄屏保持单列。

## 承担职责

- 后台运行结果的统一深链接落点。
- 提供稳定业务摘要、结构化结果、关联对象、领域入口和诊断信息。

## 不承担职责

- 不复制收藏同步、分发、解析等完整业务界面。
- 不用一个通用按钮猜测所有任务的重试方式或绕过领域策略。

## API 关联

- 领域：`../../backend/api/agent-system-events.md`
- 主要读取：`GET /api/v1/background-tasks/runs/{run_id}`。

## 当前边界

- 已覆盖收藏同步、内容解析/重解析/摘要/语义索引、发现、分发、平台/AI 连通性和 Bot 群组同步。
- 未知任务展示通用标题与状态，保留原始诊断数据，不发明业务动作。
