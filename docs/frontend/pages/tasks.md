# 任务结果页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/dashboard/task_result_page.dart`
- 路由：`/tasks/:runId`

## 用户任务与当前界面

用户可以通过稳定 `runId` 查看持久化后台运行的业务标题、状态、摘要、结果 section、关联对象、时间和下一步入口。任务结果使用根导航，和内容详情同层，查看日志后返回仍回到原内容；任务页保留应用级暂停/播放会话。页面支持加载失败重试和手动刷新；原始 metadata/result 默认折叠到“技术详情”。前端严格消费后端 `presentation`，不再从任意字段拼展示摘要或目标路由。

结果、下一步操作、运行信息与技术详情按阅读顺序排列，使用分组间距和分隔线组织，不为每组重复包裹大卡片。已由明确动作指向的同一地址不再重复放入关联对象；其他关联仍可访问。结果字段沿用后端 tone，失败数值有明确颜色强调。

页面不提供通用业务重试，因为不同任务的权限、参数和副作用不同。收藏同步使用专用 renderer 复用既有 run、单项和批量 retry contract；服务端领域策略仍是权威边界。其他任务当前只提供安全导航动作。

收藏同步最近运行和历史 highlight 均跳转本页，不再打开第二套运行详情弹窗。

## 自适应行为

- Compact/手机横屏使用单列，基础字段允许标签和值换行，不依赖固定横向表格。
- 收藏同步失败标题与重试操作使用自适应排列；窄屏或大字号放不下时，按钮移到下一行，避免把平台名称挤成竖向文字列。
- 宽屏使用居中的连续阅读区域；结果字段按宽度和字号使用一至两列，运行时间字段在空间允许时同行排列，大字号自动换行，不为少量辅助信息固定占一整列。
- 技术字段统一左对齐，展开区域不再出现默认上下边线；窗口变化保留技术详情展开状态。大型 payload 保持可滚动、可选择，不撑破页面宽度。
- 技术详情采用共享动效时序，支持展开过程中反向操作，减少动画直接展开/收起；只有错误代码而没有 metadata/result 时仍提供该入口。无时间或额外关联信息时不生成空的运行信息分组。

## 承担职责

- 后台运行结果的统一深链接落点。
- 提供稳定业务摘要、结构化结果、关联对象、领域入口和诊断信息。

## 不承担职责

- 不复制收藏同步、分发、解析等完整业务界面。
- 不用一个通用按钮猜测所有任务的重试方式或绕过领域策略。

## API 关联

- 领域：`../../backend/api/agent-system-events.md`
- 主要读取：`GET /api/v1/background-tasks/runs/{run_id}`。

## 当前边界

- 已覆盖收藏同步、内容解析/重解析/摘要/语义索引、发现、分发、平台/AI 连通性和 Bot 群组同步。
- 未知任务展示通用标题与状态，保留原始诊断数据，不发明业务动作。

解析任务未返回业务status时不补造“已完成”；异常和运行中记录沿用真实任务状态及诊断信息，明确跳过仍显示已跳过。

加载失败界面允许纵向滚动，短横屏和大字号下仍可阅读完整错误并操作重试。

收藏失败项的单项/批量重试同时传回收藏夹ID和名称，恢复后保持原集合来源。
