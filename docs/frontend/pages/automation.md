# 自动化页面

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/automation/automation_page.dart`
- 路由：`/automation`

## 用户任务与当前界面

页面以总览和三个领域组织自动化：收藏同步、分发、解析/后处理。总览展示各领域的健康摘要、主要数量和需要处理的问题；进入领域后再显示具体配置、队列、历史或诊断。

- 收藏同步：查看平台状态、策略摘要、最近运行，执行预览、同步和失败重试。
- 分发：管理规则、目标和队列，查看推送历史，执行单条或批量操作。
- 解析/后处理：查看账号、发现源、推送目标和处理链路的健康摘要，并进入测试或修复入口。

规则编辑、危险删除、回填确认和短表单仍使用弹出界面；复杂运行详情仍存在重复弹层，这是待收敛问题。

## 自适应行为

- 总览在宽屏并列展示领域入口，窄屏纵向排列。
- 分发领域宽屏采用规则与队列并列，窄屏先选择规则再查看队列。
- 健康摘要在宽屏多列、窄屏单列；操作区允许换行。

## 承担职责

- 自动化健康总览和三大领域入口。
- 收藏同步、分发规则/队列和处理链路诊断。
- 展示外部副作用执行前后的可见状态。

## 不承担职责

- 不承担账号登录和解绑主流程。
- 不承载全部系统设置。
- 不复制通用任务结果 renderer。
