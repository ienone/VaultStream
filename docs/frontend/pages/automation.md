# 推送与内容处理

## 文档状态

active

## 用户任务与入口

推送工作区合并待发送、发送记录、规则和目标。内容处理策略位于 `/settings?tab=processing`。

- `/sources/sync`：全平台同步、预览、全局同步策略与运行历史。自动同步及允许手动同步未启用平台的开关、间隔、批量与平台速率直接显示。单平台开关和操作已归入 `/accounts/:platform`。
- `/automation/distribution`：查看和处理推送。
- `/automation/distribution/rules`：自动规则列表，支持启停、编辑和删除，侧滑露出删除按钮，点击后确认删除。
- `/automation/distribution/rules/new`、`/automation/distribution/rules/:ruleId`：同一分发工作区的规则配置。
- `/automation/distribution/history`：已发送记录。
- `/settings?tab=processing`：解析、归档、摘要与索引策略及运行状态。

## 手动推送闭环

收藏卡片菜单、收藏详情菜单、收藏批量操作和动态条目的“推送”共用目标选择表单。选择目标后直接发送，不要求先建立自动规则，也不改变内容的收藏或全局审批状态。

表单只列出已启用、可访问且允许推送的目标；没有目标时可进入目标管理。提交期间禁用重复操作和退出，结果区区分已发送、已发送过并跳过、失败或未收到发送回执，并提供“查看推送”。只有逐项发送接口返回 success 才计为已发送。

## 推送列表

待发送与发送记录共用规则筛选，筛选通过 `?rule=ID` 保存在地址中。规则列表承担规则管理，宽屏编辑已有规则时提供规则侧栏；新建时规则列表保留新建入口。新建入口位于规则列表内容上方，编辑页显示规则标题和返回按钮。离开编辑页检查未保存修改；目标管理以弹层打开，关闭后保留规则草稿。手机沿用四个主导航图标。

来源中的机器人消息开关控制监听，推送目标开关控制发送用途，账号详情控制会话总开关。三个控制点对应不同后端字段，停用会话后不能通过用途开关隐式重新启用。

队列采用紧凑内容行，展示标题、实际目标、状态或包含日期的本地发送时间。点击进入内容详情，菜单提供立即发送、设置日期和时间、选择、取消发送；长按也可进入批量模式，批量操作区停靠列表底部，退出使用图标，发送与取消发送使用并列按钮，空间不足时换行；选择框替换行尾菜单，进入多选不插入列表顶部内容、不挤动标题；取消最后一项、处理完全部选中项或列表更新移除全部选中项时自动退出多选。加载更多读取后续页。已移除拖拽排序、装饰时间块和前端自行推算排期。

正在发送或未收到回执的记录不能批量重发。未收到回执只呈现为发送失败事实，不要求人工核对或填写消息 ID。

自动发送开关控制自动 worker，关闭后仍可显式立即发送；设置未来时间只完成排期，不冒充已送达。

## 自动规则

表单按三步组织：发送哪些新内容、发到哪里、怎么发送。条件包含来源平台、包含／排除标签及标签匹配方式；发送方式包含人工确认、发送频率、消息格式和敏感内容策略。备注可选。新增目标只接收绑定后新内容，历史内容从收藏库显式选择发送；表单不再叠加历史回填配置。

规则及完整目标集合在一次请求、一个事务内保存；无效目标使整个保存失败。保存失败保留草稿，成功后返回来源。启停只提交 enabled，不将未修改字段发送为 null。删除会移除规则及关联队列，已发送记录保留；存在发送中记录时后端拒绝删除；未收到回执的历史记录解除规则关联后保留。

未保存保护仍覆盖系统返回、顶栏返回、浏览器历史和刷新；切换主分支保留草稿。保存按钮位于表单末尾，所有高度均随表单滚动。短横屏和大字号不依赖固定底栏腾出输入空间。

## 解析／后处理

解析、归档、摘要、索引按实际能力与策略展示，失败内容进入收藏详情，后台任务进入 `/tasks/:runId`。账号问题归入账号中心，不混入处理阶段。自动聚合及其外发开关仍独立控制。内容处理采用限宽的连续设置行，按保存归档与理解整理分组，模型配置只保留一个入口；开关保存中禁止重复提交，失败就地反馈。失败条目优先展示内容标题，不把内部编号作为日常名称。

解析与索引统计作为独立的可换行信息项显示，策略状态另行呈现；同步平台、运行结果和时间分层排列。预览中的新增与已有数量保留各自标签，不用点号串联。

## 验证边界

静态分析与构建只证明各自边界。隔离 API 验收覆盖规则目标原子写入、发送前确认、手动发送、去重、未知结果保护、计数和迁移，网络发送适配器使用本地替身，不代表 Telegram／QQ 真实送达。

推送目标位于 `/automation/distribution/targets`。规则编辑内管理目标只切换工作区页签，保留未保存表单；保存校验会滚动并聚焦规则名或缺失的发送目标。自动分发和目标开关显示保存进度与失败反馈。

窄屏规则筛选采用单行菜单，不再使用满宽双行表单。批量取消一次提交所有选中队列项，服务端完成后立即移出列表，队列事件统一由数据层刷新分页和统计，页面不重复订阅刷新。

推送与来源使用同样的靠起始侧排列、可横向滚动的工作区页签。进入规则编辑后，规则列表与编辑器各自拥有顶部栏，工作区页签不再挤入编辑表单。列表宽度和分栏形状复用共享工作区。

管理型子页面共用 `AppPageBody`：正文在当前可用区域内居中，最大宽度复用工作区尺寸，列表外边距 16，顶部留白 24。推送目标、同步平台使用连续成组列表；队列与发送记录的可选缩略图置于文字右侧，标题起点不随图片有无变化。无启用平台时禁用全平台同步与预览；运行结果的 `platform_count` 为 0 时显示“未执行平台同步”。运行记录整行进入详情，失败记录保留重试入口。发送记录加载后立即展示，不使用逐项延迟淡入。

规则表单限制在 720dp 阅读宽度内，发送目标使用勾选菜单，推送格式使用原生 RadioGroup 与分组列表；平台、频率及敏感内容复用共享单选菜单。
