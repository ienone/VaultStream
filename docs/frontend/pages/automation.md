# 自动化页面

## 文档状态

active

## 用户任务与入口

`/automation` 提供收藏同步、推送和解析／后处理三个入口。

- `/automation/sync`：全平台同步、预览、全局同步策略与运行历史。单平台开关和操作已归入 `/accounts/:platform`。
- `/automation/distribution`：查看和处理推送。
- `/automation/distribution/rules`：自动规则列表，支持启停、编辑和删除，侧滑露出删除按钮，点击后确认删除。
- `/automation/distribution/rules/new`、`/automation/distribution/rules/:ruleId`：同一分发工作区的规则配置。
- `/automation/distribution/history`：已发送记录。
- `/automation/processing`：解析、归档、摘要与索引策略及运行状态。

## 手动推送闭环

收藏卡片菜单、收藏详情菜单、收藏批量操作和动态条目的“推送”共用目标选择表单。选择目标后直接发送，不要求先建立自动规则，也不改变内容的收藏或全局审批状态。

表单只列出已启用、可访问且允许推送的目标；没有目标时可进入目标管理。提交期间禁用重复操作和退出，结果区区分已发送、已发送过并跳过、失败或未收到发送回执，并提供“查看推送”。只有逐项发送接口返回 success 才计为已发送。

## 推送列表

宽屏左侧列出规则，右侧为“推送 / 发送记录 / 配置”页签。分发路由共用持久工作区，点击规则只更新右侧配置，不重建左侧导航和页头；自动分发总开关仅位于“全部内容”的配置滚动内容内，具体规则和新建规则不展示全局开关，也不设置固定开关栏。切换页签保留表单草稿，切换规则或离开时仍检查未保存修改。窄屏在同一工作区切换列表与表单。新建规则位于页头右上角，复用其他主页的填充加号按钮；未保存的新规则在推送和发送记录页签保持空白。全部内容与规则行共用圆角 Material 点击表面，用总览图标及间距区分总分层级。规则区固定采用顶部栏滚动后的色调，右侧内容区保持原背景色，不使用明线。推送只显示待发送队列，发送记录复用原已发送队列的数据与分页，按实际发送时间从新到旧排列，保留逐条渐入动画；不再显示未发送栏目或旧推送历史列表。

队列采用紧凑内容行，展示标题、实际目标、状态或包含日期的本地发送时间。点击进入内容详情，菜单提供立即发送、设置日期和时间、选择、取消发送；长按也可进入批量模式，批量操作区停靠列表底部并按宽度换行；选择框替换行尾菜单，进入多选不插入列表顶部内容、不挤动标题；取消最后一项仍保留选择模式，显式取消后退出。加载更多读取后续页。已移除拖拽排序、装饰时间块和前端自行推算排期。

正在发送或未收到回执的记录不能批量重发。未收到回执只呈现为发送失败事实，不要求人工核对或填写消息 ID。

自动发送开关控制自动 worker，关闭后仍可显式立即发送；设置未来时间只完成排期，不冒充已送达。

## 自动规则

表单按三步组织：发送哪些新内容、发到哪里、怎么发送。条件包含来源平台、包含／排除标签及标签匹配方式；发送方式包含人工确认、发送频率、消息格式和敏感内容策略。备注可选。新增目标只接收绑定后新内容，历史内容从收藏库显式选择发送；表单不再叠加历史回填配置。

规则及完整目标集合在一次请求、一个事务内保存；无效目标使整个保存失败。保存失败保留草稿，成功后返回来源。启停只提交 enabled，不将未修改字段发送为 null。删除会移除规则及关联队列，已发送记录保留；存在发送中记录时后端拒绝删除；未收到回执的历史记录解除规则关联后保留。

未保存保护仍覆盖系统返回、顶栏返回、浏览器历史和刷新；切换主分支保留草稿。保存按钮位于表单末尾，所有高度均随表单滚动。短横屏和大字号不依赖固定底栏腾出输入空间。

## 解析／后处理

解析、归档、摘要、索引按实际能力与策略展示，失败内容进入收藏详情，后台任务进入 `/tasks/:runId`。账号问题归入账号中心，不混入处理阶段。自动聚合及其外发开关仍独立控制。内容处理采用限宽的连续设置行，按保存归档与理解整理分组，模型配置只保留一个入口；开关保存中禁止重复提交，失败就地反馈。失败条目优先展示内容标题，不把内部编号作为日常名称。

## 验证边界

静态分析与构建只证明各自边界。隔离 API 验收覆盖规则目标原子写入、发送前确认、手动发送、去重、未知结果保护、计数和迁移，网络发送适配器使用本地替身，不代表 Telegram／QQ 真实送达。
