# 自动化页面

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/automation/automation_page.dart`
- 路由：`/automation` 总览，`/automation/sync` 收藏同步，`/automation/distribution` 分发队列与规则，`/automation/distribution/history` 推送历史，`/automation/distribution/rules/new` 新建规则，`/automation/distribution/rules/:ruleId` 规则详情与编辑，`/automation/processing` 解析 / 后处理。

## 用户任务与当前界面

页面以总览和三个领域组织自动化：收藏同步、分发、解析/后处理。总览以三个普通列表入口展示领域名称和最小运行概况，不再包圆角卡片，不再设置跨域“需要处理”面板。进入领域后由独立 URL 还原具体配置、队列、历史或处理阶段，浏览器刷新和任务结果链接不会丢失当前位置。

- 收藏同步：总览下提供全平台操作，再查看各平台连接与启用状态；已连接平台提供预览和同步，账号问题直接前往连接或检查。低频调度策略和各平台速率折叠在其后，最近运行显示本地时间与可读范围，不把已启动调度器称作正在同步。
- 分发：管理规则、目标和队列，查看推送历史，执行单条或批量操作。规则栏不保留未接线的搜索框，空规则只使用已有新建入口；选择“全部内容”会清除规则条件并保留状态筛选。待推送、不推送、已推送分别使用准确的队列空态，保留刷新，不放装饰和劝休文案。
- 总览只保留领域名称、必要范围和真实运行状态；加载、失败与真实零计数分开表达。同步调度器启动不等于正在执行同步；统计 contract 缺字段进入失败状态，不补成零。
- 队列与规则、推送历史使用标准 Material 次级标签栏，完整显示名称；选中项由所在路由决定，浏览器或系统返回时恢复父页的队列标签，避免只变正文而标签仍停在历史。
- 队列状态筛选以单行文字和数量呈现，宽度不足时横向滚动，避免装饰图标挤压数量并造成换行裁切。
- 分发队列预览由列表 API 批量返回卡片用途的 `media_assets`，按后端候选顺序显示封面；没有匹配资产时显示占位，不再读取旧 `cover_url`。
- 解析/后处理：按解析、媒体归档、摘要、全文/语义索引分组，展示策略状态、队列数量、失败内容和最近运行；配置进入对应设置分区，run 进入 `/tasks/:runId`，失败内容进入收藏详情。账号问题继续由独立账号中心承担，不再把账号、发现源和推送目标混成处理阶段。
- AI 连通性和发现源质量检查由 provider 解码为 typed result；页面只读取类型字段展示成功、错误和任务跳转，不再解析动作响应 map。

保存成功后释放退出保护并返回已有分发父页；请求失败保留草稿。独立打开规则页时，列表 provider 若在请求期间已释放，不再对已销毁的 Ref 执行刷新；下次读取本身即重新请求，避免后端保存成功却显示前端失败。

规则表单按名称、匹配条件、目标、执行方式组织，优先级、频率、时间窗和回填收在高级设置；消息样式使用同级独立展开区，不再嵌套在高级设置中；无目标时直接进入推送目标管理。复杂规则的新建和编辑使用可刷新、可返回的独立页面；危险删除、回填确认和短表单仍使用弹出界面。后台运行详情统一跳转 `/tasks/:runId`，领域页不再复制结果弹层。

领域、分发历史和规则页使用嵌套路由及平台转场，删除整页重复淡入。规则页返回分发时保留队列状态筛选和列表。规则未修改时允许预测性返回；修改后，系统返回、顶栏返回和取消均先询问是否放弃，继续编辑保留草稿。浏览器历史后退和路由替换通过 GoRouter 的退出回调复用同一确认；取消后恢复规则地址与草稿，放弃后才退出。普通跨主分支切换仍保留原表单，鉴权失效必须离开私有页面。保护包括尚未添加为标签的输入、目标选择及高级设置；保存期间阻止关闭和继续操作表单。普通主分支切换保留规则页；重复点击当前主导航先尊重表单的返回拦截，继续编辑不丢草稿，放弃后回到分发页。未修改时可直接退回自动化总览。

规则存在未保存修改或正在保存时，Web 会注册浏览器离开提醒；清空修改、保存放行或销毁表单后解除。该提醒也覆盖暂时切到其他主分支但仍挂载的规则草稿。浏览器提示由浏览器决定，不能代替草稿持久恢复；移动系统强制结束进程不保证触发。

## 自适应行为

- 规则表单按实际可用高度安排操作区：普通窗口固定显示取消/保存；横屏软键盘等低矮视口将操作区放入表单滚动末尾，避免按钮和留白挤掉正在输入的字段。旋转和键盘开关保留焦点与草稿。
- 总览始终是限宽的三个列表入口，保留自然留白；不为铺满桌面展开成三张大卡片。
- 分发领域在自身可用宽度达到 expanded 时采用独立规则栏与队列并列，compact / medium 在队列前选择规则。策略、领域标签、规则选择、状态筛选和内容共用一个纵向滚动区域；加载、失败、空态和推送历史沿用相同阅读顺序。低矮窗口和播放器占用空间时可以滚走控制区，完整查看内容及刷新/重试。
- 队列实例和自身滚动控制器跨宽度断点保留，旋转不清除本地批量选择和滚动位置；待推送列表使用 SliverReorderableList，拖动继续调用既有最终索引排序接口。
- 处理阶段使用无外框的标题分组，在自身可用宽度达到 expanded 时两列，否则单列；操作区允许换行，失败内容在所属解析阶段内联显示。

- 短横屏的分发开关与队列/历史标签按实际宽度同排或换行，取消固定 220dp 策略宽度；控制区整体滚动，顶栏为 48dp。规则详情直接进入已有规则页，不再在队列上方展开另一套配置面板。规则侧栏改为普通选择行，保留启用开关、审批状态与操作菜单。

## 视觉语义

- 总览、规则、队列、同步与 Bot 编辑 surface 使用共享 `AppShape`、`AppMotion`、`ColorScheme` 和 `TextTheme`；平台来源统一使用共享徽标。
- 队列常态不使用装饰阴影；只在拖拽代理和悬浮批量工具栏保留明确的浮起反馈。窄屏或大字号将时间和操作移到正文下方，来源与辅助字段允许换行；没有封面不保留封面间距。批量栏空间不足时采用具名图标按钮，并保留取消选择。
- 规则栏用自己的 Material 绘制选中和点击反馈，避免被背景遮住。窄屏规则选择复用 AppFilterMenu，圆角菜单在根 Navigator 打开，选中行与墨水反馈按外轮廓裁切，返回取消保留来源；排期快捷菜单同样使用根浮层并尊重减少动画。推送历史的平台与状态允许换行。
- 自动化与规则页使用标准 Material 3 tonal AppBar，不使用毛玻璃工具栏。
- 规则名称、标签、说明及渲染模板文本沿用主题输入表面，取消/保存沿用主题按钮。回填选项按可用宽度换行；高级设置不使用展开后的硬分隔线，渲染开关在所属分组内平铺，避免逐项叠加卡片。

## 承担职责

收藏同步平台卡片展示后端声明的范围和限制；未接入平台的开关禁用，并隐藏执行、账号跳转和同步速率配置，不能以连接账号提示代替真实能力缺口。Bilibili 复用已有账号与同步控制面。能力字段按统一命名响应解析。

- 自动化健康总览和三大领域入口。
- 收藏同步、分发规则/队列和处理链路诊断。
- 展示外部副作用执行前后的可见状态。

## 不承担职责

- 不承担账号登录和解绑主流程。
- 不承载全部系统设置。
- 不复制通用任务结果 renderer。

排期时间入口由同一层 Material 承载底色和交互反馈，去掉隐藏 hover/splash/highlight 的局部主题与内部无操作 InkWell。窄屏独立时间块保持全圆角，宽屏连接卡片的时间区保持左侧圆角，触发反馈与各自外形一致；菜单选项沿弹出层轮廓裁切。临时样本已验证键盘进入、取消后再打开和焦点绘制，真实待推送队列为空时不据此宣称实际排期操作已验收。


单条与批量排期属于一次完成的简单选择，使用紧凑表单对话框，不额外进入二级页面。标题、并列的小时/分钟字段和底部操作形成单一阅读顺序；采用与队列一致的 24 小时制，以普通数字输入替代大尺寸表盘和模式切换。外框随内容收缩，确认使用主按钮、取消使用次要按钮，不再叠加装饰分界线或额外内容卡片。共用自适应表单处理键盘和短高度滚动，保留输入并显示范围错误；确认与取消继续返回既有时间结果，不改变日期换算、过期时间处理或排期提交规则。

规则中的包含／排除标签使用只承担显示和删除的 Chip，添加按钮分别标注“添加包含标签／添加排除标签”，移除按钮包含所属条件与标签名。长标签限行并保留完整提示；删除仅修改所属条件草稿，保持未保存退出保护和保存中禁用逻辑。

### 规则编辑的层次与空间（2026-09-13）

复杂规则继续使用二级页面。分组用中性色标题、对齐和间距表达，目标、历史处理及消息样式不再额外套背景板或叠加分界线。目标复选框位于名称前，长名称自然换行，目标列表随整页滚动，取消固定 220dp 高度和内部滚动；数量与全选／清空工具允许换行。无目标时使用简短说明与添加入口，不保留空卡片。

审批和启用归入“如何执行”，使用与消息样式一致的 Material 开关。数字字段按可用宽度和字号排列为一至三列。高级设置与消息样式沿纵向展开／收起，使用共享时序并尊重减少动画；无预设模板时不显示空标题或额外间距。条件、目标选择、历史范围、提交和退出保护仍由既有状态与回调负责。

消息样式内部以中性标题区分预设、显示控制、内容模式与模板文本，去掉重复的字段图标。模式选项保持单选，用紧凑的主题选项控件显示当前值；宽屏名称与选项并列，窄屏／大字号改为上下排列且允许选项换行。头尾模板使用多行输入并随内容增高，便于检查实际换行；预设应用与配置字段继续沿用原逻辑。

收藏同步预览仍是执行前的一次性检查，采用自适应对话框。先呈现预计新增数量及平台结果，全平台预览默认折叠候选样本，单平台默认展开；失败原因直接显示。样本以状态、完整标题和可复制链接顺序排列，移除逐项背景板、边框和挤占标题的图标。展开采用共享纵向动效并尊重减少动画，短高度操作随正文滚动，确认结果继续由原调用方处理。

收藏同步主页面限制阅读宽度，平台启用开关使用具名 Material 控件；平台之间只保留单一分隔，不另套背景层。策略菜单共用主题圆角与根级弹层，按可用宽度和字号单列／双列排列，说明紧邻所属字段。运行错误完整换行，查看记录与重试位于正文下方，不挤占错误说明；策略展开使用共享纵向时序并尊重减少动画。

处理页新增“多来源自动聚合”与“聚合结果推送”独立控制。聚合默认关闭，提示文本模型接收每批最多 30 条正文的前 6000 字符、首次最近 24 小时；运行结果提供综合稿入口且明确待核实。推送默认关闭并约束已有队列，开启后仍遵循分发规则和全局暂停，不自动补推全部历史结果。
