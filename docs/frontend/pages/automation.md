# 自动化页面

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/automation/automation_page.dart`
- 路由：`/automation` 总览，`/automation/sync` 收藏同步，`/automation/distribution` 分发队列与规则，`/automation/distribution/history` 推送历史，`/automation/distribution/rules/new` 新建规则，`/automation/distribution/rules/:ruleId` 规则详情与编辑，`/automation/processing` 解析 / 后处理。

## 用户任务与当前界面

页面以总览和三个领域组织自动化：收藏同步、分发、解析/后处理。总览以三个普通列表入口展示领域名称和最小运行概况，不再包圆角卡片，不再设置跨域“需要处理”面板。进入领域后由独立 URL 还原具体配置、队列、历史或处理阶段，浏览器刷新和任务结果链接不会丢失当前位置。

- 收藏同步：先查看平台连接与启用状态，直接前往账号连接或检查；已连接平台提供预览和同步。低频调度策略折叠在其后，最近运行显示本地时间与可读范围，不把已启动调度器称作正在同步。
- 分发：管理规则、目标和队列，查看推送历史，执行单条或批量操作。规则栏不保留未接线的搜索框，空规则只使用已有新建入口；选择“全部内容”会清除规则条件并保留状态筛选。待推送、不推送、已推送分别使用准确的队列空态，保留刷新，不放装饰和劝休文案。
- 总览只保留领域名称、必要范围和真实运行状态；加载、失败与真实零计数分开表达。同步调度器启动不等于正在执行同步；统计 contract 缺字段进入失败状态，不补成零。
- 队列状态筛选以单行文字和数量呈现，宽度不足时横向滚动，避免装饰图标挤压数量并造成换行裁切。
- 分发队列预览由列表 API 批量返回卡片用途的 `media_assets`，按后端候选顺序显示封面；没有匹配资产时显示占位，不再读取旧 `cover_url`。
- 解析/后处理：按解析、媒体归档、摘要、全文/语义索引分组，展示策略状态、队列数量、失败内容和最近运行；配置进入对应设置分区，run 进入 `/tasks/:runId`，失败内容进入收藏详情。账号问题继续由独立账号中心承担，不再把账号、发现源和推送目标混成处理阶段。
- AI 连通性和发现源质量检查由 provider 解码为 typed result；页面只读取类型字段展示成功、错误和任务跳转，不再解析动作响应 map。

规则表单按名称、匹配条件、目标、审批/启用组织，优先级、时间窗、回填和渲染等高级项折叠；无目标时直接进入推送目标管理。复杂规则的新建和编辑使用可刷新、可返回的独立页面；危险删除、回填确认和短表单仍使用弹出界面。后台运行详情统一跳转 `/tasks/:runId`，领域页不再复制结果弹层。

## 自适应行为

- 总览始终是限宽的三个列表入口，保留自然留白；不为铺满桌面展开成三张大卡片。
- 分发领域在自身可用宽度达到 expanded 时采用规则与队列并列，compact / medium 先选择规则再查看队列。
- 处理阶段使用无外框的标题分组，在自身可用宽度达到 expanded 时两列，否则单列；操作区允许换行，失败内容在所属解析阶段内联显示。

- 短横屏把分发开关与队列/历史选择放在同一行，规则和状态筛选缩短垂直间距；顶栏为 48dp。规则详情直接进入已有规则页，不再在队列上方展开另一套配置面板。规则侧栏改为普通选择行，保留启用开关、审批状态与操作菜单。

## 视觉语义

- 总览、规则、队列、同步与 Bot 编辑 surface 使用共享 `AppShape`、`AppMotion`、`ColorScheme` 和 `TextTheme`；平台来源统一使用共享徽标。
- 队列常态不使用装饰阴影；只在拖拽代理和悬浮批量工具栏保留明确的浮起反馈。
- 自动化与规则页使用标准 Material 3 tonal AppBar，不使用毛玻璃工具栏。

## 承担职责

- 自动化健康总览和三大领域入口。
- 收藏同步、分发规则/队列和处理链路诊断。
- 展示外部副作用执行前后的可见状态。

## 不承担职责

- 不承担账号登录和解绑主流程。
- 不承载全部系统设置。
- 不复制通用任务结果 renderer。
