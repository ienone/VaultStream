# 动态页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/dashboard/dashboard_page.dart`
- 路由：`/home`

## 当前事实

当前页面仍主要是系统概览，而不是目标中的信息流。它展示内容、存储、队列和失败统计，发现候选摘要、近期趋势、后台运行时间线和诊断信息，并提供到收藏库、自动化、设置或任务结果的跳转。

页面支持刷新、连接失败重试和按 `run_id` 打开运行详情。当前运行详情仍有本页弹出层，与统一任务结果页重复。

## 目标职责

动态页应逐步成为近期信息流入口：浏览订阅、发现、同步和 Agent 推荐内容，理解聚合/推荐理由，并执行收藏、忽略、稍后处理等轻量动作。

系统统计只保留真正影响当前使用的少量摘要；完整队列、诊断和任务 JSON 移交自动化或任务页。

## 自适应行为

- 当前概览区会随宽度改变列数和排列。
- 后续信息流在宽屏可增加详情预览，窄屏进入独立详情。
- 连接失败、无近期内容、加载中和存在高优先级异常必须采用不同状态。

## 承担职责

- 当前：全局近期状态与跨模块跳转。
- 目标：用户每日浏览的个性化信息流。

## 不承担职责

- 不长期承担收藏专属统计、完整后台诊断、队列管理或重复任务详情。
- 不恢复独立收件箱页面。

## API 关联

- 当前读取 dashboard、discovery stats 和 background task diagnostics。
- 目标信息流 contract 尚未稳定，不能根据旧 discovery API 猜测实现。
