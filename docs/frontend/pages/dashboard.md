# 动态页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/dashboard/dashboard_page.dart`
- 路由：`/home`

## 当前事实

当前页面不是系统仪表盘，而是近期动态入口。新动态与稍后处理由 discovery 候选驱动；条目展示真实来源、发布时间、来源正文预览和卡片用途的统一媒体资产。事件变化视图读取进行中的知识事件，按真实更新时间排列，显示成员数量与最新关联内容并进入独立事件详情。页面支持下拉刷新、内容分页、进入内容/事件详情、收录、忽略、稍后处理和恢复。收录会把候选转为收藏内容；忽略与稍后处理都会从新动态移出，其中稍后条目保留在独立列表并可移回，全部动作都通过后端状态持久化。当前代码没有近期趋势、后台运行时间线、诊断列表或本页 run 弹层。

旧 Bot 状态、系统健康、探索饼图和通用 donut 概览组件没有真实页面调用方，已随动态页职责收敛删除；需要这些信息时进入自动化、设置或对应任务详情，不在 `/home` 保留隐藏备用实现。

## 目标职责

动态页应逐步成为近期信息流入口：浏览订阅、发现、同步和 Agent 辅助筛选的内容，并执行收藏、忽略、稍后处理等轻量动作。日常条目不展示内部评分、“为什么推荐”或模型式可信说明。

系统统计只保留真正影响当前使用的少量摘要；完整队列、诊断和任务 JSON 移交自动化或任务页。

## 自适应行为

- 动态流在宽屏保持有阅读上限的居中内容列，在手机、平板横竖屏和桌面上使用同一信息层级。
- 条目详情使用独立语义路由；窄屏与宽屏都不会把详情误留在 Root Shell 内。
- 连接失败、无近期内容、加载中和存在高优先级异常必须采用不同状态。

## 承担职责

- 当前：用户每日浏览并轻量处理候选内容，同时查看人工知识事件的近期变化。
- 目标：继续接入用户主动探索、自动事件更新生产和 Agent 辅助筛选能力。

## 不承担职责

- 不长期承担收藏专属统计、完整后台诊断、队列管理或重复任务详情。
- 不恢复独立收件箱页面。

## API 关联

- `GET /api/v1/discovery/items` 返回候选列表、正文预览、全部关联来源上下文和 `purpose=card` 的 `media_assets`。
- `PATCH /api/v1/discovery/items/{id}` 以 `promoted`、`ignored`、`snoozed` 或 `visible` 持久化轻量动作；`visible` 用于撤销后恢复候选。
- `GET /api/v1/knowledge-events?status=active` 返回按更新时间排列的进行中事件变化入口。
