## 用户任务与当前界面

用户可以创建和切换会话、发送自然语言请求、查看流式回复、引用、工具过程和使用量信息。当前运行可停止或重做，会话可以清空。

空会话只保留输入区，不放示例任务或能力宣传；输入提示不承诺未经支持的同步、规则创建或批量推送。模型用量与确认参数默认折叠，确认摘要和确认/拒绝动作始终可见。

未发送输入按 Agent 会话保存在本地，切换会话或重新打开页面时恢复对应草稿；从搜索入口带入的新问题优先于该会话旧草稿，并成为新的未发送输入。成功发起请求或清空会话时同步删除草稿，不把已提交内容再次恢复到输入框。

后端工具目录现包含单链接/单段文字的 `capture_content`。模型选择该工具后，工作台按现有 write 工具流程展示具体保存摘要和确认动作；批准后内容进入正式收藏、来源记录和后处理链路。附件、跨消息相册、事件合并和模板/成本推断不属于该工具当前 contract。

`organize_knowledge_event` 可在明确内容 ID 下创建事件，或把内容加入明确事件 ID。工作台在批准前展示动作对象、成员角色和证据状态；批准后从持久化 tool message 恢复中文分类摘要以及可点击的内容、事件引用。该能力不从相似度猜测事件，也不自动合并、拆分或综合事件。

Agent 工作台可从三个主页的页头工具菜单进入。`search_content` 的引用按内容、人工知识事件和音视频时间点区分图标与标签，并分别进入 `/collection/:id`、`/events/:id` 或带 `t`、`media_asset` 的内容详情；时间点会交给同一应用级播放器精确起播。三类结果交错排列，有限展示时不会因内容结果较多而完全遮住事件或时间点证据。

工具结果由后端持久化为会话消息。页面重新进入或刷新会话时，会把保存的结构化 payload 恢复为同一种工具结果和可点击引用；旧版只含 `items` 的内容结果仍可读取。

同一个 `tool_call_id` 的调用和结果原位更新为一条记录，保留参数、结果与引用；重复结果不追加卡片，延迟到达的调用事件不把已完成状态改回调用中。未知 SSE 事件不把原始 payload 输出到对话。

普通工具调用在对话中默认只显示一行状态，用户主动展开后才显示参数或原始结果；工具失败会自动展开错误详情。事件动作摘要与可定位引用不随技术详情折叠，仍直接可见。

需要确认的高风险工具以内联内容出现在原对话位置，展示工具、参数摘要和确认/拒绝动作，避免用户脱离调用上下文。

待确认项由后端持久化。刷新页面、重新进入会话或从 `/notifications` 的 Agent 消息深链进入 `/agent?session_id=...` 时，页面会读取该会话的 pending confirmations 并恢复确认卡；停止运行、清空或删除会话后旧确认不能再执行。确认按钮在提交期间禁用，避免重复决定。

加载、加载失败、空会话、运行中、工具失败、确认等待和普通错误都有独立可见状态；首次连接失败时只展示明确的重试入口，不留下无法工作的假空会话。错误会保留可用于排查的 request ID 信息。

## 自适应行为

- 页面按自身可用尺寸读取统一窗口类别：`expanded` 以上且高度不紧凑时，同时显示会话 supporting pane 和当前对话。
- `compact` / `medium` 以及短横屏只显示当前对话，通过 AppBar 的显式会话入口打开 end drawer；选择或创建会话后关闭 drawer，不再用固定高度的横向 chip 条占用正文空间。
- `large` 以上且当前会话确有工具事件时增加“证据与运行”第三 pane，集中展示可定位引用和工具状态；没有工具证据、宽度不足或高度紧凑时不保留空 pane，引用回到对话内联展示。
- 会话 supporting pane 使用统一辅助栏宽度；消息流、错误提示和输入区使用统一可读正文宽度，超宽屏不会把对话拉满。
- 输入区避让系统安全区域，输入与发送合为一个表面。回车用于换行，发送由显式按钮触发；空输入禁用发送，运行中同一按钮变为停止，顶栏不重复放停止动作。短横屏限制输入区可见行数，长草稿仍可内部滚动。
- 会话 supporting pane 与自适应 drawer 共用按 session ID 隔离的草稿状态，布局切换不会改变草稿归属。

## 视觉语义

- 用户消息保留右侧气泡；回复直接进入阅读流，不为每条消息重复放人物或机器人图标。工具过程、待确认动作和错误分别使用低层 surface、`tertiaryContainer` 与 `errorContainer`。
- 待确认动作使用较高层级的语义 pane 形状；普通消息、工具结果和错误使用内容卡片形状。
- 滚动跟随使用共享内容切换动效 token，不在页面内另定义时长和曲线。

## 承担职责

- 会话与消息浏览。
- 受控 Agent 运行、工具过程和确认。
- 展示可恢复、可定位的内容、事件、媒体时间点引用、事件组织结果和可诊断错误。

## 不承担职责

- 不绕过后端权限和自动化策略。
- 不替代设置、账号、收藏或分发的确定性主界面。
- 不直接暴露底层媒体或模型供应商接口。
