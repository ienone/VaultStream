# 全局搜索页

## 文档状态

active

分组内采用可点击的列表行和分隔线，不为每条命中重复套卡片。搜索结果只展示有命中的分组；指定类型没有结果时直接显示无结果状态，不用其他类型或多张空分组补位。没有搜索历史时保留搜索输入区，历史词来自用户实际查询。

## 用户任务

用户从 Root Shell 的全局工具入口搜索已经持久化的内容与知识事件，并从结果进入原始内容或事件详情。复杂问题可以把当前查询交给 Agent 工作台继续处理。目标上的统一上下文搜索与轻量 Agent 交接见[前端方案](../../plans/2026-06-10-frontend-information-architecture-redesign.plan.md)，尚未取代当前收藏库内搜索。

## 当前实现

- 路由为 `/search`，稳定参数包括 `q`、`kind` 和 `content_scope`。
- `kind` 支持全部、内容、事件、人物、主题、时间点和文档页码；`content_scope` 约束内容及由内容派生的人物、主题、时间点结果，支持收藏库、发现和全部内容。
- 内容结果读取 `GET /search/unified` 中的混合语义检索结果，展示标题及可用的作者、摘要；不展示内部平台代码或检索算法标签。
- 知识事件只按事件标题、描述、成员备注和成员内容的标题、摘要、正文匹配；不把词法匹配伪装成向量检索，也不在正常首屏堆放检索实现说明。
- 人物由混合检索命中及 `author_name` 精确召回的内容聚合，主题由混合检索命中及 `tags` 精确召回的内容聚合；直接查作者或标签不依赖 embedding。点击后分别以稳定 `author` / `tag` 参数进入收藏库筛选，不创建虚构人物或主题实体。
- 音视频时间点只读取带 `segment_type`、`media_asset_id`、`start_seconds` 的章节或转写切片。后端会核验媒体资产属于命中内容、类型为音频或视频且秒数未越过已知时长；发布日期不会被当作时间点。
- 内容进入 `/collection/:id`，事件进入 `/events/:id`。时间点进入 `/collection/:id?t=...&media_asset=...`，详情页选择对应媒体资产并把显式秒数交给应用级播放器。
- “交给 Agent”把查询预填到 `/agent?prompt=...`。Agent controller 会建立或恢复正式 session，但不会在用户再次确认发送前自动调用模型。
- 空查询在输入区下方展示与收藏库共用的本地搜索历史；执行查询后替换当前搜索 URL 并收起键盘，保留进入搜索前的页面和返回路径。清除按钮同时清除查询和旧结果，保留类型与范围。无结果和错误状态可在短屏中滚动。
- 结果列表的滚动控制属于 `/search` 页面本身。进入内容、事件或媒体时间点详情后按系统返回，会恢复原查询、结果类型、内容范围和像素位置，不重新请求同一结果；真正修改查询或筛选时回到新结果顶部。

## 响应式行为

- 输入、筛选、历史及结果共用页面滚动；短横屏与键盘出现时仍可滚动到输入或错误重试。搜索输入与单列结果最大宽度 720dp，分组标题、文本与分隔线对齐。
- Compact / Medium 使用单列结果流；七种结果类型和三种内容范围使用带标题及当前值的圆角选择控件。窄屏或大字号自然换行，事件类型隐藏不适用的内容范围；区域高度变化使用共享时序，减少动画直接到终态。
- 筛选菜单使用根 Navigator 的标准弹出路由，显示在应用级播放器上方，短屏可滚动到最后选项。支持 Tab、方向键、Enter、Esc 及系统返回；打开菜单前释放搜索输入焦点，选择或取消后不重新弹键盘。
- 结果区自身可用宽高达到 Expanded supporting-pane 条件且有多个非空分组时，“全部”类型以两列排列结果；单一分组使用单列。
- 页面按真实结果、目标类型和返回流程做浏览器专项验收；原有按文案/布局断言的 widget 套件已删除。

## 不承担职责

- 不生成答案或综合事件。
- 不把人物或主题聚合伪装成独立实体。
- 不从发布日期、媒体总时长或模型猜测生成时间点；没有显式带时间的章节/转写切片就返回空结果。
- 不自动执行 Agent 请求或任何有副作用的工具。
- 不替代收藏库内面向当前列表的筛选和批量操作。

## 尚未完成

- Bilibili 解析已生产平台章节和字幕，普通摘要保持这些来源片段；时间点搜索/定位已有真实样本证据。任意音视频的 ASR/章节生产仍未形成，不能把平台字幕外推为通用转写。调用链与边界见[重审证据](../../knowledges/product-review-2026-09-14/README.md#e5)。
- 搜索建议目前只有历史记录，没有后端建议或意图分类。
- 搜索框到结果页的共享容器形变、真实 embedding 质量和跨端辅助技术仍未全面验收。2026-09-12 已实测 Web 菜单键盘操作、Android 菜单系统返回、真实输入法及详情返回后的原滚动位置；浏览器历史手势和完整预测性返回进度仍待专项验收。

## 文档页码（2026-09-10）

类型选择新增文档页码；非空结果显示文件名、页号和命中片段，点击使用后端给出的对应文件原页 route。该分组与内容、事件、人物、主题、时间点并列，既有查询和返回状态继续保留。
