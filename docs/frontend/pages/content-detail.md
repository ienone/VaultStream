# 内容详情页

## 文档状态

active

## 当前代码

- 页面：`frontend/lib/features/collection/content_detail_page.dart`
- 路由：`/collection/:id`

## 用户任务与当前界面

用户在这里阅读一条存档，查看来源、作者、正文、媒体、标签和统计，并执行编辑、删除、重新解析、加入事件或打开原文等内容级动作。加入事件允许创建新事件或选择已有事件，并要求明确内容角色与证据状态；已有关联显示为可进入事件详情的关系区。来源行在后端提供作者头像时显示小尺寸圆形头像，并沿用统一媒体源优先级与鉴权头；缺失头像时直接省略，不显示无意义占位。

内容动作统一由 `ContentActions` 消费命名响应。重新解析返回后台 run 时提示“已触发”；摘要与巡逻评分的 HTTP contract 在返回前已经完成，因此提示“已生成/已完成”。这些动作缺少 contract 要求的 `run_id` 时按无效服务响应处理，不静默显示成功。

人工修改过的字段会在详情辅助区标明为“已保护”。重新解析前，界面明确说明这些字段不会被覆盖；若解析值与当前人工值不同，详情在窄屏纵向、宽屏并排展示两个版本，并允许逐字段采用新解析、保留当前或编辑最终合并值。一次决策只影响一个字段；尚未处理的候选继续保留。编辑对话框只提交真正发生变化的字段，避免把未改动值误标为人工修订。

详情头按“平台与内容类型 → 标题 → 作者身份与时间”分层，不把所有元信息挤在同一横排。宽屏时作者、来源与时间进入右侧信息栏，窄屏时才回到标题下方；顶栏是唯一的原文入口。知乎回答把关联问题标题与问题统计合并进详情头，不再在正文前重复渲染关联问题卡。宽屏目录使用独立的低层级背景容器，与正文和其他辅助信息形成区分。文章向下阅读越过标题后，右侧栏以平滑停靠状态显示当前文章标题。

封面、笔记配图、媒体说明和主页简介属于可选内容，缺失时省略；主页身份只在公共详情头展示一次，真实头像继续保留在来源行。文章正文、图集主媒体及音视频文件缺失仍有明确状态，不猜测未抓取的原因；仅有有效外部原文地址时提供来源播放动作。

详情根据内容的有效布局与平台内容类型选择文章、图文笔记、短帖子、图集、视频、音频、聚合页、主页或书签结构。音视频详情读取后端已校验的 `media_segments`；章节与逐字稿同时存在时分别保留并用分段控件切换，不再因存在章节而隐藏逐字稿。点击任一条目会在同一个应用级播放会话中定位，不创建第二个播放器。展开播放器可为带持久资产的音视频记录当前时间点及可选笔记，书签再次点击仍定位这一会话；视频还可隐藏画面进入仅听声音模式，当前位置、章节、队列和书签继续属于原会话。当前媒体、位置、队列、倍速和仅听声音偏好会在应用重启后以暂停状态恢复，睡眠定时器不会跨重启继续；关闭播放器会删除这份会话快照。若另一条媒体已在播放，当前详情明确提供立即替换或加入同一会话队列，不静默中断原内容；旧会话被关闭后，仍停留的媒体详情会接管并建立新会话。宽屏下，图文笔记、带媒体的短帖子、图集和带主页媒体的账号主页采用沉浸式媒体阅读器：左侧媒体占据主舞台，右侧按“平台 → 作者与时间 → 标题与正文 → 统计 → 标签”组织内容，不再叠加第三列辅助栏。多图媒体保留底部缩略图条；鼠标进入媒体区后显示悬浮左右切换按钮，页码、缩略图和按钮使用与全屏媒体工具栏一致的玻璃表面。纯文字短帖使用紧凑正文卡片，标题与正文重复时不再单独放大标题；引用内容区分作者、正文与原文动作。失败时应保留替代信息和重试/原文路径。详情页不展示处理流水线，摘要、索引、归档、评分和分发等运行状态统一归入自动化与任务页。

加载时优先保持从列表传入的内容上下文；详情头在共享容器内延续已知标题与来源，正文和宽屏辅助栏使用与最终布局一致的骨架。加载失败、内容被删除和媒体失败均有独立状态。

卡片进入详情时只共享一套不透明容器，直接展开到详情头的真实位置；飞行层在卡片快照与详情头之间交叉过渡，正文与辅助栏直接显示，避免重复淡入使阅读内容长时间半透明。沉浸式媒体模板从加载首帧起就建立与最终页面一致的左媒体、右内容双栏，唯一 Hero 的几何目标是右栏真实标题头，而不是双栏外框的左上角；左侧媒体舞台独立显现，右侧其余内容随后淡入并轻微横移。短帖的列表缩略图可能只是链接预览，不能单独证明详情会采用沉浸式双栏；只有结构化媒体资产或明确封面存在时，短帖加载态才把共享标题目标放到右栏，否则保持普通阅读流的左侧标题目标。返回使用更短的收拢时长。详情正文和媒体不建立第二套 Hero；深链接、来源卡片不存在或系统减少动效时使用普通页面转场。

富文本正文、引用、代码块、统计、媒体网格、骨架和全屏图集使用共享 TextTheme、ColorScheme、AppShape 与 AppMotion。正文和标题采用可读的正文前景色，段间距收紧；章节层级由字号与字重表达，不为每级标题分配装饰色。Markdown 样式不按明暗模式缓存带颜色的 ThemeData 派生值，因此同一亮度下切换系统动态色或内容主题后会立即使用新配色；代码块也不固定某套浅/深灰值。

## 自适应行为

- 窄屏使用单一阅读流，媒体、元信息和正文按阅读顺序排列。
- 宽屏只在内容适合时使用阅读区与上下文区并列，不强制所有模板双栏。
- 小红书等图文笔记以及带媒体的短帖、图集和账号主页在宽屏使用整页左媒体、右内容的沉浸式双栏；空间不足时退回纵向阅读流。
- 横竖屏切换应保留阅读位置和当前媒体页。
- 解析候选在窄屏上下对照、宽屏左右对照，决策按钮使用可换行布局，不依赖固定宽度。

## 承担职责

- 单条内容的阅读、媒体浏览和人工维护。
- 展示来源证据与已生成的内容摘要。
- 发起内容级后台动作并链接其运行结果。

## 不承担职责

- 不承担全局自动化诊断、账号修复或长期任务归档。
- 不展示或操作后台处理流水线；相关诊断和动作归入自动化与任务页。
