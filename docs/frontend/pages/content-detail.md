# 内容详情页

## 文档状态

active

## 用户任务与当前界面

文档附件区排除作者头像、封面及海报，只列出内容文件；附件行显示文件名和可用的大小，不显示 MIME 技术标识或空副标题。

内嵌 PDF 的滚轮用于滚动阅读页，不同时缩放原页；双指缩放保留，放大后可平移查看。

用户在这里阅读一条存档，查看来源、作者、正文、媒体、标签和统计，并执行推送、编辑、删除、重新解析、加入事件或打开原文等内容级动作。推送从更多菜单进入共用目标选择表单。加入事件允许创建新事件或选择已有事件，并要求明确内容角色与证据状态；已有关联显示为可进入事件详情的关系区：使用标题与整行事件入口，长名称自然换行，不套彩色底板或标签。单列正文后的辅助区以留白分组，移除无条件分界线。来源行在后端提供作者头像时显示小尺寸圆形头像，并沿用统一媒体源优先级与鉴权头；缺失头像时直接省略，不显示无意义占位。

详情读取失败直接呈现错误与重试，不通过自动退避持续显示骨架。HTTP 404 显示“内容不存在”和返回收藏库入口，不推测为连接故障。

阅读器按自身可用宽度、字号与高度选择布局；内嵌和独立入口共用此规则。空间足够时恢复模板辅助栏、文章目录或沉浸式媒体布局。收折收藏列表和跨断点保留阅读状态；单列与带侧栏的正文使用同一阅读树。文章作者与时间初始位于标题下，越过实际标题区域后，标题、作者、时间与统计随滚动连续进入侧栏。窄屏文章目录使用底部悬浮入口。

内容动作统一由 `ContentActions` 消费命名响应。重新解析返回后台 run 时提示“已触发”；摘要与巡逻评分的 HTTP contract 在返回前已经完成，因此提示“已生成/已完成”。这些动作缺少 contract 要求的 `run_id` 时按无效服务响应处理，不静默显示成功。

人工修改过的字段会在详情辅助区标明为“已保护”。重新解析前，界面明确说明这些字段不会被覆盖；若解析值与当前人工值不同，详情在窄屏纵向、宽屏并排展示两个版本，并允许逐字段采用新解析、保留当前或编辑最终合并值。一次决策只影响一个字段；尚未处理的候选继续保留。编辑页只提交真正发生变化的字段，避免把未改动值误标为人工修订。

详情头按“平台与内容类型 → 标题 → 作者身份与时间”分层，不把所有元信息挤在同一横排。作者、来源与时间初始位于标题下方，滚动后进入右侧上下文区；顶栏是唯一的原文入口。知乎回答按“问题标题与问题回答数/关注数 → 回答作者与时间 → 回答赞同数/评论数 → 回答正文”分组，关联对象的统计不混入回答作者区域。宽屏目录使用独立的低层级背景容器，与正文和其他辅助信息形成区分。文章向下阅读越过标题后，右侧栏以平滑停靠状态显示当前文章标题。

封面、笔记配图、媒体说明和主页简介属于可选内容，缺失时省略；主页身份只在公共详情头展示一次，真实头像继续保留在来源行。文章正文、图集主媒体及音视频文件缺失仍有明确状态，不猜测未抓取的原因；仅有有效外部原文地址时提供来源播放动作。

短帖、图文笔记、图集和主页保留全部可播放音视频附件，图片存在时也不隐藏播放器入口。附件复用全局播放会话，普通阅读由用户主动播放，媒体定位链接只激活对应资产。图文笔记的宽屏布局由详情工作区统一负责，不在模板内部再维护一套双栏。引用块使用色调背景区分；书签原文入口统一在顶栏，解析失败时不重复排列解析按钮。

详情根据内容的有效布局与平台内容类型选择文章、图文笔记、短帖子、图集、视频、音频、聚合页、主页或书签结构。音视频详情读取后端已校验的 `media_segments`；章节与逐字稿同时存在时分别保留并用分段控件切换，不再因存在章节而隐藏逐字稿。点击任一条目会在同一个应用级播放会话中定位，不创建第二个播放器。展开播放器可为带持久资产的音视频记录当前时间点及可选笔记，书签再次点击仍定位这一会话；视频还可隐藏画面进入仅听声音模式，当前位置、章节、队列和书签继续属于原会话。当前媒体、位置、队列、倍速和仅听声音偏好会在应用重启后以暂停状态恢复，睡眠定时器不会跨重启继续；关闭播放器会删除这份会话快照。若另一条媒体已在播放，当前详情明确提供立即替换或加入同一会话队列，不静默中断原内容；关闭会话后，仍保留的媒体详情显示播放入口，由用户点击后重新建立会话。宽屏下，图文笔记、带媒体的短帖子、图集和带主页媒体的账号主页采用沉浸式媒体阅读器：左侧媒体占据主舞台，右侧按“平台 → 作者与时间 → 标题与正文 → 统计 → 标签”组织内容，不再叠加第三列辅助栏。多图媒体保留底部缩略图条；鼠标进入媒体区后显示悬浮左右切换按钮，页码、缩略图和按钮使用与全屏媒体工具栏一致的玻璃表面。纯文字短帖使用紧凑正文卡片，标题与正文重复时不再单独放大标题；引用内容区分作者、正文与原文动作。失败时应保留替代信息和重试/原文路径。详情页不展示处理流水线，摘要、索引、归档、评分和分发等运行状态统一归入自动化与任务页。

加载时优先保持从列表传入的内容上下文；详情头延续已知标题与来源，正文和宽屏辅助栏使用与最终布局一致的骨架。加载失败、内容被删除和媒体失败均有独立状态。

收藏与动态共用同一个工作区。列表条目与详情之间不再使用 Hero 飞行；布局变化由连续列表和分栏承担。媒体模板保留真实媒体选择与播放状态，图片查看器的独立图集交互不属于列表转场。

富文本正文、引用、代码块、统计、媒体网格、骨架和全屏图集使用共享 TextTheme、ColorScheme、AppShape 与 AppMotion。正文和标题采用可读的正文前景色，段间距收紧；章节层级由字号与字重表达，不为每级标题分配装饰色。Markdown 样式不按明暗模式缓存带颜色的 ThemeData 派生值，因此同一亮度下切换系统动态色或内容主题后会立即使用新配色；代码块也不固定某套浅/深灰值。

内容编辑页有未保存修改或正在提交时，Web 会注册浏览器刷新/关闭提醒；放弃确认期间仍保留，退出编辑后解除。应用内返回与浏览器历史返回使用同一草稿确认。浏览器卸载提醒不等于自动保存或系统强制结束后的草稿恢复。

## 自适应行为

- 窄屏使用单一阅读流，媒体、元信息和正文按阅读顺序排列。
- 收藏工作区的阅读器按自身空间选择辅助栏，空间不足时使用单列；列表可收折，阅读器保留返回入口。
- 独立详情宽屏只在内容适合时使用阅读区与上下文区并列，不强制所有模板双栏。
- 文章、图文笔记和文档正文沿用统一阅读宽度上限；文档原页与文本不会随桌面窗口无限拉宽，窄屏仍填满可用阅读区。
- 独立详情中的小红书等图文笔记以及带媒体的短帖、图集和账号主页在宽屏使用整页左媒体、右内容的沉浸式双栏；空间不足时退回纵向阅读流。
- 横竖屏切换应保留阅读位置和当前媒体页。
- 解析候选使用单一低层级表面，字段与版本依靠标题和间距分组；窄屏或大字号上下对照，宽屏左右对照，决策按钮可换行。
- 正文合并使用独立编辑页面，宽屏完整版本并排且分别滚动，窄屏或短高度将新解析版本折叠在编辑区上方，可完整展开。短字段沿用自适应表单弹窗，不再把新解析截断成输入提示。切换布局保留草稿和输入焦点，未应用修改在退出前确认；应用仍返回最终文本给原逐字段处理回调，不改变后端保存与失败提示。

## 承担职责

- 单条内容的阅读、媒体浏览和人工维护。
- 展示来源证据与已生成的内容摘要。
- 发起内容级后台动作并链接其运行结果。

- 不展示或操作后台处理流水线；相关诊断和动作归入自动化与任务页。

## PDF 阅读（2026-09-10）

原文件、保存说明和文档正文分别显示。PDF 正文按文件资产选择与页码翻页，完整文本可选择复制；扫描或空白页明确没有原生文本。重新提取通过 ContentActions 调度并链接任务结果，SSE 完成事件刷新正文。document_asset 与 page 深链接选择具体文件原页并滚动至阅读区，失效页码不默默替换成另一页。原页预览已另行接入，原生文本提取仍不包含 OCR。

混合文件内容按资产顺序保留全部附件入口，不因采用文档模板而隐藏图片、音频或视频。音视频附件复用全局播放器，普通阅读时由用户点击播放；带明确媒体资产的定位链接只激活对应附件。

## 阅读层级调整（2026-09-11）

AI 摘要属于阅读前的概览，在标题之后、正文之前展示；宽屏沉浸布局中位于文字列正文之前，不再放在页尾或次要信息栏。长摘要默认展示四行并可展开，短摘要直接完整显示；没有摘要不占位。

标题与来源融入页面阅读表面，不再额外套一张有底色的卡片；加载头与宽屏沉浸头沿用同一原则。共享转场仍保持不透明材质，摘要保留轻量底色以区分模型概览与原文。

阅读区的标签合并为一组静态主题标记，同名平台标签与自定义标签只展示一次；悬停或长按可查看来源。该操作只改变展示，不修改存储中的标签归属，也不把没有筛选动作的标签表达成复选框。

点赞、收藏、评论等来源统计使用可换行的紧凑图标文字，不采用类似操作按钮的高亮方块，也不再为统计单独包一张卡片。数值和平台语义沿用原有数据映射。

短帖子标题与正文开头相同（包括以省略号截断的标题）时，直接以正文开始阅读，避免再放大重复一次；带人工标题修改标记的内容始终保留标题。普通与沉浸布局共用同一判断。

竖屏图集和图文笔记采用单张焦点图、横向切换及缩略图导航，明确提供“查看大图”。全屏内切换图片同步回详情的焦点图。全屏图片使用模糊背景与随日夜模式变化的底部工具条。

纵向阅读流中的焦点图按当前媒体资产的实际宽高展示，不再把所有图片放进固定竖框；缺少有效尺寸时使用方形展示区。内嵌高度不超过窗口高度的 70%，长图完整缩放并可进入全屏。切图尺寸变化沿顶边平滑过渡，减少动画时直接到位；分页控制器和选中图片保持不变。

当前图片位置由详情页持有，普通焦点图与宽屏沉浸图切换时恢复同一页；全屏切图同样更新该状态。切换到另一条内容重置图片位置，附件数量变少时将位置限定在有效范围内。此处为当前详情生命周期中的状态，不承诺重启应用后恢复阅读图片。

本轮优先整改阅读层级；不同模板、列表、工具页面的一致性及横竖屏切换仍需继续逐页验收，不能仅以摘要和图集改动声明客户端整体完成。

代码块保留原始缩进与换行，支持选择文本和整段复制；语言标签在窄屏与大字号下限制为一行并可通过提示查看完整名称，复制按钮保留独立触控空间，代码长行保持横向滚动。

Markdown 表格采用可读列宽并随正文字号放大，单元格内容自然换行，宽表在独立区域横向滚动并显示滚动条；不再把所有列压缩进手机屏幕。

文章正文已引用的图片不在页尾重复展示；末尾“其他图片”仅保留正文未引用的附件，点击仍对应全屏图集中的原始位置。图片引用从 Markdown 节点提取，支持引用式链接及带标题的图片，代码示例不作为图片引用。匹配沿用完整媒体候选 URL，不猜测文件名。

## PDF 原页预览（2026-09-11）

文档阅读默认展示原页，保留“原页 / 文本”切换。原页按实际 PDF 页数翻页并支持缩放，使用相同文件资产和 page 深链接；文本尚未提取时仍可查看原页。文件不存在或引用页越界明确提示，不替换成另一份文件。翻页复用已打开的文档引用。

PDFium 在客户端本地渲染，不调用模型。文件按现有 manifest 候选读取，资源请求不携带控制面密钥；授权拒绝立即停止、签名过期单次刷新、本地文件缺失提交核验。预览上限为 64 MiB，失败提供手动重试和既有原文件入口。

本机引擎图形渲染、手机尺寸组件翻页、凭据边界已验证。Android 长文档与缩放的有效验收结果见下文，不再将已完成的原生双指操作列入待办；这些结果不替代 Web 或其他设备的视觉证据。

原页工具栏将上一页／页码／下一页作为一组，目录与缩略页为辅助工具；窄屏或大字号分行，宽屏将导航按钮保持在紧凑分组内。点击页码进入限宽数字输入弹窗，可直接跳到有效页面，不生成整份文档的页码下拉选项。范围校验使用当前 PDF 的真实页数，键盘确认与按钮共用同一跳转路径。 页码、目录和缩略页弹窗复用共享预测性返回预览；只关闭当前阅读工具，不改变页码或弹出底层详情，减少动画时不进行手势位移与缩放。

文件包含内置目录时，原页工具栏提供目录入口；目录以可滚动列表保留章节层级，章节标题与子项使用不同文字层级，页码位于标题下方，避免挤占长标题。弹窗减少外侧空白并限制桌面阅读宽度，反馈与选中状态沿统一圆角呈现，点击有效章节定位到对应原页。没有目录不显示空入口；无目标的分组标题保留，越界目标不允许跳转。目录基于文件自身书签，不由模型或提取文本猜测。

原页与文本切换时保留当前文件的原页组件、已读取数据和页码，不重复下载 PDF；离开阅读区或更换文件后仍按生命周期释放资源，不建立全局永久文件缓存。

原页工具栏提供“浏览缩略页”，以当前打开的 PDF 按可用宽度及页码标签的实际文字宽度排列页面缩略图；打开时定位当前页，选择后回到对应原页。缩略图高度结合页面比例、标签高度与可用空间，短横屏避免宽卡片只承载很小的页面图片；列数变化时优先保持仍在可视区的当前页，否则保持正在浏览的首行附近位置。横屏仍可同时看到页面和页码；懒加载网格复用已有文档，不重新下载或调用模型。当前页具有选中语义，所有缩略页有可执行的选择操作。

## 内容编辑页面（2026-09-13）

持续编辑标题与长正文使用 `/collection/:id/edit` 二级页面，替换旧编辑弹窗。页面复用 ContentEditor 和现有 ContentActions，只有实际变动字段才进入更新请求；无改动时保存禁用。正文自然增高并随整页滚动，不在六行输入框中建立第二个滚动区。标题与正文采用无底板的书写区域，以字号、间距和限宽形成层级；标签随后排列，作者与封面地址直接排列在标签下方。模板切换继续使用详情菜单中的独立选择器。

保存固定在顶部，键盘压缩高度时仍可访问；短高度使用紧凑正文级输入字号并隐藏已填字段的浮动标签，为实际输入保留空间，恢复正常高度后回到标题层级；提交错误留在页头，输入保留。返回是退出编辑的统一入口，有改动时询问继续编辑或放弃，保存期间阻止重复提交和退出。普通页面转场沿用平台 Material 路由，放弃确认沿用共享弹层时序及减少动画设置。
