# Navigation Shell

## 文档状态

active

## 当前代码

- `frontend/lib/layout/app_shell.dart`
- `frontend/lib/layout/root_page_actions.dart`
- `frontend/lib/core/layout/responsive_layout.dart`

## 当前职责

- 桌面侧栏固定显示四个工作区的名称和图标；选中时改变图标底色。

- 主导航仍为动态、收藏库、来源、推送四个目的地。`NavigationSidebar` 将主导航与全局工具分组，宽屏不再在每页 AppBar 重复展开搜索、Agent、消息、账号和设置。侧栏内容可滚动，紧凑模式保留 tooltip 与语义。
- 侧栏宽 72dp，设备安全区保留在栏外。手机底栏显示四个工作区名称；左上角菜单提供助手、消息、设置和外观切换。键盘出现时隐藏底栏。
- 主页 AppBar 复用 `layout/root_page_actions.dart` 的保存按钮和导航入口；保存与分发新建规则使用同款填充加号、圆角和交互反馈。窄屏时，带未读提示的导航按钮位于标题左侧，与左侧抽屉的进入方向一致；常驻侧栏可见时不重复显示或预留按钮位置。保存与局部刷新、筛选仍在右侧动作区。抽屉和常驻侧栏共享工具目的地，分别使用行列表与紧凑栏；选择模式保留关闭按钮，子页保留返回按钮，不混入全局动作。
- 工具按钮和消息菜单项沿用同一个持久化消息未读计数。SSE 到达后重读事实 API，Web 端保留既有低频刷新。服务端空闲心跳 30 秒，客户端失活阈值 90 秒；替换连接与销毁时通过 http AbortableRequest 中止旧响应流，旧流迟到的事件/错误不得触发新的连接或更新当前状态。
- 消息图标以小圆点提示未读，具体数量进入 tooltip 和无障碍名称；抽屉打开期间仍随事实 API 更新。零未读不显示圆点或数量。
- 包装 `StatefulNavigationShell`，普通分支切换及 侧栏/底栏切换保留页面状态；重复点击当前目的地沿当前栈返回；无拦截时到分支根页面，遇到未保存表单或正在提交的操作则停下并复用页面的退出处理。继续编辑保持原页，放弃后回到该表单的父页面。
- 系统分享沿用同一捕获表面；mini player 在导航之外、正文下方维持当前全局播放会话。

## 不承担职责

- 不执行业务动作。
- 不持有页面业务状态。
- 不决定账号、设置或自动化的功能边界。

## 状态与输入输出

- 输入：`StatefulNavigationShell` 当前分支、屏幕宽高、用户点击的导航目标。
- 输出：自适应侧栏/抽屉、移动底栏、全局工具入口和当前分支内容。
- 副作用：只执行路由跳转，不直接调用业务 API，也不在普通分支切换时重置收藏库筛选。

## 响应式和失败态要求

- 手机竖屏底栏提供四个工作区；保存位于主页页头，工具位于侧栏或同源抽屉。改变窗口尺寸时立即适配，保留正文与各分支状态。
- 内容处理位于 `/settings?tab=processing`；规则和推送历史保留 `/automation/distribution` 工作区上下文。Shell 只在分支根页面处理返回动态，子页面交给对应 Navigator。
- 消息使用壳内状态分支，整个页面在侧栏右侧打开；入口仍在工具组，手机从工具抽屉切换，不显示业务底栏，抽屉同时提供返回四个工作区的入口。
- Agent、设置、来源账号与内容处理也使用壳内状态分支。设置地址保留分区 query，内部 Material 页面栈承接窄屏列表与分区的逐层返回；宽屏通过主导航切换工作区。当前分区子树跨单双栏保留，根弹层优先处理返回。
- 正文与 mini player 避让横向安全区，侧栏布局避让底部系统区域；不覆盖 AppBar，不创建第二套内容状态或播放控制器。
- 正文分支 Navigator 使用独立语义容器，页面遮罩只屏蔽该内容区域内的旧页面，不把左侧主导航从读屏树中移除。根级弹窗仍屏蔽背景导航；关闭后恢复选中项、页面和草稿。

根弹窗关闭后的系统返回能力由当前活动导航栈共同决定：根 Navigator 的单次通知不能覆盖仍可返回的分支页面或祖先 PopScope。动态根页无拦截时继续交给系统退出；不把所有系统返回永久截留。

`AppNavigationScope` 将祖先 Shell 的可见状态传入子 Navigator；Android 的平台过渡同时检查该状态与分支 TickerMode，避免根弹窗打开时底层详情抢走预测性返回。页面自己的未保存拦截继续有效，分支容器仍使用 GoRouter 的 indexedStack。隐藏页面的返回通知不再向外冒泡；GoRouter 的 Shell 拦截通过安装后补丁只对启用 TickerMode 的分支生效。保留自动化子栈回动态后的桌面预览、取消及提交已在 Android 36 验证；可见表单的退出保护仍有效，详见导航文档。

## 设计约束

主导航只承载 Root Shell 高频业务入口。消息盒子、设置、任务详情、独立账号中心、Agent/RAG 等均不得作为同级主导航项；需要保留的工具或深链入口应放入全局工具区或具体业务下钻。账号对象与连接动作不再作为设置 Section Shell 的长期目标职责。

主侧栏采用 surfaceContainerLowest，收藏列表采用 surfaceContainerLow，批量操作栏采用 surfaceContainerHigh，底部播放器采用 surfaceContainerHighest，通过不同表面色调区分职责，不增加硬分隔线。

页头工具栏由应用主题统一为常规 64dp、紧凑高度 56dp，系统状态栏安全区另行保留。窄屏内容详情进入根级 Material 页面，覆盖主导航和底栏，返回恢复来源列表的位置。

手机工具抽屉直接提供浅色、跟随系统、深色外观切换，复用全局持久偏好；不重复主导航，不增加占位说明。

手机底栏显示四个工作区的图标与名称；手机横屏侧栏也保留这四个入口，助手、消息、设置收在更多菜单。桌面侧栏有独立的工具区。

列表与详情工作区复用 `core/layout/app_list_detail_workspace.dart`：收藏、动态、来源与账号、消息、设置分区、Agent 会话和推送规则共用可调整的列表宽度与分栏边界形状。宽度偏好在工作区间同步；每个面板的标题和操作归属自身顶部栏，工作区页签不放入对象编辑区。横屏工作区从首帧固定左列表或功能选项、右详情；收藏库另提供可切换的全宽卡片视图。固定分栏时，加载、空结果和未选择时保持两栏宽度。加载中在对应栏显示骨架，列表有数据后展示当前项或首项详情。两栏各自滚动。窄屏只显示当前对象，返回和未保存保护由业务路由负责。

桌面与竖屏侧栏上部保留动态、收藏库、来源、推送；Agent、消息和设置位于底部工具区。四个主入口固定显示标签，消息保留未读标记。

左栏标题居中，动态、来源与推送的页签位于左栏顶部，与详情顶栏等高。页签按实际标签宽度居中排列，省略已由主导航表达的工作区标题，指示线与标签文字等宽；长标签与大字号超出可用宽度时横向滚动。窄屏左上角保留抽屉按钮，常驻侧栏可见时隐藏；底部不提供“更多”入口。Agent、消息与设置属于工具分支，窄屏隐藏业务底栏，抽屉内提供四个工作区入口。
