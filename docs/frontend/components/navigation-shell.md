# Navigation Shell

## 文档状态

active

## 当前代码

- `frontend/lib/layout/app_shell.dart`
- `frontend/lib/layout/root_page_actions.dart`
- `frontend/lib/core/layout/responsive_layout.dart`

## 当前职责

- 主导航仍为动态、收藏库、自动化三个目的地。`NavigationSidebar` 将主导航与全局工具分组，宽屏不再在每页 AppBar 重复展开搜索、Agent、消息、账号和设置。侧栏内容可滚动，紧凑模式保留 tooltip 与语义。
- 侧栏支持自动、展开、仅图标、隐藏四种偏好并本地持久化；展开宽 224dp，仅图标宽 72dp。自动模式在 large 及以上展开、medium/expanded 显示图标；显式展开在小于 expanded 时临时降为图标。compact 隐藏侧栏，保留标准底部 NavigationBar，键盘出现时隐藏底栏。响应式降级不覆盖用户偏好。
- 三个主页 AppBar 复用 `layout/root_page_actions.dart` 的保存按钮和导航入口。侧栏隐藏时，带未读提示的导航按钮位于标题左侧，与左侧抽屉的进入方向一致；常驻侧栏可见时不重复显示或预留按钮位置。保存与局部刷新、筛选仍在右侧动作区。抽屉与常驻侧栏复用同一组件及布局菜单；选择模式保留关闭按钮，子页保留返回按钮，不混入全局动作。
- 工具按钮和消息菜单项沿用同一个持久化消息未读计数。SSE 到达后重读事实 API，Web 端保留既有低频刷新。服务端空闲心跳 30 秒，客户端失活阈值 90 秒；替换连接与销毁时通过 http AbortableRequest 中止旧响应流，旧流迟到的事件/错误不得触发新的连接或更新当前状态。
- 消息图标以小圆点提示未读，具体数量进入展开侧栏标签和 tooltip；抽屉打开期间仍随事实 API 更新。零未读不显示圆点或数量。
- 包装 `StatefulNavigationShell`，普通分支切换及 Rail/Bar 切换保留页面状态；重复点击当前目的地沿当前栈返回；无拦截时到分支根页面，遇到未保存表单或正在提交的操作则停下并复用页面的退出处理。继续编辑保持原页，放弃后回到该表单的父页面。
- 系统分享沿用同一捕获表面；mini player 在导航之外、正文下方维持当前全局播放会话。

## 不承担职责

- 不执行业务动作。
- 不持有页面业务状态。
- 不决定账号、设置或自动化的功能边界。

## 状态与输入输出

- 输入：`StatefulNavigationShell` 当前分支、屏幕宽高、用户点击的导航目标。
- 输出：自适应侧栏/抽屉、移动 `NavigationBar`、全局工具入口和当前分支内容。
- 副作用：只执行路由跳转，不直接调用业务 API，也不在普通分支切换时重置收藏库筛选。

## 响应式和失败态要求

- 手机竖屏底栏只有三个目的地；保存位于主页页头，工具位于侧栏或同源抽屉。手动收折使用共享 AppMotion；改变窗口尺寸立即适配，避免旧宽度动画挤压正文。减少动画直接到终态。
- 自动化领域通过父子路由返回 `/automation`；规则和推送历史先返回保留状态的 `/automation/distribution`。Shell 只在分支根页面处理返回动态，子页面交给对应 Navigator。
- 工具与设置使用独立路由。设置地址保留分区 query，内部 Material 页面栈承接窄屏列表与分区的逐层返回；宽屏返回退出整个工作区。当前分区子树跨单双栏保留，根弹层优先处理返回。
- 正文与 mini player 避让横向安全区，侧栏布局避让底部系统区域；不覆盖 AppBar，不创建第二套内容状态或播放控制器。
- 正文分支 Navigator 使用独立语义容器，页面遮罩只屏蔽该内容区域内的旧页面，不把左侧主导航从读屏树中移除。根级弹窗仍屏蔽背景导航；关闭后恢复选中项、页面和草稿。

根弹窗关闭后的系统返回能力由当前活动导航栈共同决定：根 Navigator 的单次通知不能覆盖仍可返回的分支页面或祖先 PopScope。动态根页无拦截时继续交给系统退出；不把所有系统返回永久截留。

`AppNavigationScope` 将祖先 Shell 的可见状态传入子 Navigator；Android 的平台过渡同时检查该状态与分支 TickerMode，避免根弹窗打开时底层详情抢走预测性返回。页面自己的未保存拦截继续有效，分支容器仍使用 GoRouter 的 indexedStack。隐藏页面的返回通知不再向外冒泡；GoRouter 的 Shell 拦截通过安装后补丁只对启用 TickerMode 的分支生效。保留自动化子栈回动态后的桌面预览、取消及提交已在 Android 36 验证；可见表单的退出保护仍有效，详见导航文档。

## 设计约束

主导航只承载 Root Shell 高频业务入口。消息盒子、设置、任务详情、独立账号中心、Agent/RAG 等均不得作为同级主导航项；需要保留的工具或深链入口应放入全局工具区或具体业务下钻。账号对象与连接动作不再作为设置 Section Shell 的长期目标职责。
