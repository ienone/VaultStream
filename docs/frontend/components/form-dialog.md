# 自适应表单弹窗

## 文档状态

active

## 当前职责

标题和长正文的持续编辑已迁移到内容编辑二级页面，解析候选的长正文合并也使用独立编辑页面，不再受弹窗宽高和动作区约束。少量参数的一次性设置继续使用此组件。

加入事件、事件信息、成员关系编辑、时间点笔记、文档页码跳转、解析候选短字段合并、排期时间、推送目标表单、收藏同步预览及平台扫码登录共用 `frontend/lib/core/widgets/adaptive_form_dialog.dart`。它统一布局、键盘空间及可返回时的手势预览；字段、草稿、提交、错误和退出确认仍由各业务组件持有，不建立第二套保存逻辑。

正常高度下，正文可滚动，主操作保持在底部；短横屏或软键盘压缩可用高度时，操作进入同一滚动流，为当前输入保留空间。宽屏限制阅读宽度，手机保留安全区和较小外边距。简单表单可指定更紧凑的最大宽度，外框随实际内容收缩，不以默认表单宽度或固定高度撑大。

尺寸和键盘变化保持同一输入树，并将聚焦输入框连同浮动标签带回可见范围。长标签与输入控件由具体表单按提供的宽度和短高度状态调整；外层不猜测字段含义。

表单负责未保存退出询问、提交中禁止重复动作或关闭，以及失败后保留输入。弹窗出现/退出和嵌套选择器仍须分别进行原生验收；共用布局不代表所有页面的预测性返回已通过。

内容编辑、正文合并、规则、事件及笔记共用 `showDiscardChangesDialog` 呈现放弃确认。它只返回用户决定，并在取消时等待确认层退出完成；是否有草稿、是否正在保存、原输入焦点以及最终退出仍由各编辑器负责。不把字段或提交策略合并为通用业务表单。

`AdaptiveFormDialog` 内部复用 `PredictiveBackDialog`，各表单不再重复包裹。只在当前路由可返回且未开启减少动画时接管手势；拖动产生克制的位移和缩放，撤回从当前状态恢复，再次拖动接续当前画面。提交使用 Navigator.maybePop，重新尊重可能变化的返回拦截；不改变原对话框结果、遮罩、焦点或表单提交策略。草稿／保存中的 PopScope 仍决定是否允许返回，嵌套路由覆盖后底层表单不接管。

内容编辑、解析候选合并和时间点笔记的放弃确认，以及 PDF 目录和缩略页等独立弹窗显式复用同一预览。共用能力已接入不代表每个表单或嵌套选择器都完成原生验收；已验证路径和快速输入的未定边界见 UI continuation process。

推送目标类型和规则匹配模式属于固定选项，使用具有独立弹出路由的 DropdownButtonFormField。选项展开时系统返回先关闭选项并恢复入口焦点，底层表单及输入保留；菜单沿用主题圆角，选项高度允许随字号增长。

独立操作确认（内容、批量内容、规则及回填、账号登录清理、书签）和批量标签编辑也复用返回预览；操作确认仅在明确确认后执行原回调。规则和事件的放弃确认处于原草稿之上，返回确认框等同继续编辑。事件表单在确认路由退出完成后恢复原先仍挂载的输入或控件焦点。
