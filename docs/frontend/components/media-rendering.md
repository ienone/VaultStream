active

## 当前职责

- 卡片按后端返回的资产顺序选择代表图片；卡片用途下，后端会把有本地变体的图片排在仅远端的封面之前。
- 图片组件按后端顺序逐一请求候选，去除空 URL 和重复 URL；当前候选加载或解码失败后才切换下一项。
- 详情封面、头像、正文图片、媒体网格和全屏图集已贯通同一候选列表；Markdown 中与 `MediaSource` 精确匹配的原图 URL 会还原为该资产的完整候选顺序。
- 小红书纯文本正文渲染保留单换行，避免后端已保存的段落再次被 Markdown 软换行规则合并。
- 视频和音频播放器按相同的候选状态机初始化，当前来源初始化失败后才尝试下一项。
- 资产来源不再在组件边界丢成裸 URL：图片、全屏图集、正文嵌套图片、卡片和队列预览持有资产/变体身份。签名过期或 410 时每个资产只自动刷新一次 manifest；403 直接进入授权失败，404 本地来源上报服务端核验后再降级。
- 音视频会先读取 `purpose=playback` 的候选；初始化失败或播放中断时串行切换下一来源，运行期切源恢复已知进度。签名媒体请求不携带全局 API Token。
- 详情主体音视频和图集内嵌视频共用应用级 `GlobalPlaybackController`；独立 Chewie 执行器与依赖已删除。图集浏览只展示播放选择，用户点击才接管现有会话。同一控制器在详情离开后继续存在，Root Shell 仅在有会话时显示 mini player；展开 `/player` 不重新创建媒体控制器。音频使用有限阅读宽度的单列；视频在足够宽的短横屏及桌面使用画面/会话信息双栏，竖屏画面在上、信息在下独立滚动。辅助栏以字号计算偏好宽度，但不超过扣除边距后可用宽度的一半；两栏各至少 280 逻辑像素，空间不足时保持单列。大字号在详情栏中滚动，不因无界放大预设栏宽而挤回上下布局。画面与信息子树在布局切换时复用，切换方向不重新激活播放器；正文避让系统安全区。
- Mini player 使用随字号增长的最小高度，显示标题及实际存在的加载、失败或仅听声音状态；不常驻“点击展开”说明，展开意图由可访问提示表达。短横屏缩小预览区与最小高度，为正文让出空间，操作按钮保持独立触控区域。键盘显示时暂时隐藏并让出布局空间，保留原播放器子树与会话，收键盘后恢复。Shell 内与独立深层页面使用相同规则。
- 播放队列属于同一个播放会话，不复用自动化分发队列。已有媒体播放时打开另一条音视频详情不会静默抢播，而是提供“立即播放”和“加入队列”；`/player` 可播放、移除和拖动排序待播项，每项只保留一个明确拖动手柄，当前媒体正常结束时自动续播下一条。当前媒体、位置、队列、倍速和仅听声音偏好写入本地会话快照；应用重启后以暂停状态恢复，并按媒体资产 ID 重新读取播放 manifest，不持久化资产签名 URL。关闭播放器会清空运行会话、队列和快照。
- `/player` 的播放设置直接作用于同一媒体控制器：支持 0.75x、1x、1.25x、1.5x、2x 倍速，并可设置 15、30、60 分钟后暂停。倍速和定时使用统一主题菜单，倍速以勾选标记显示当前值，定时显示停止时间；不以常驻按钮组挤占横屏信息栏。视频可切换为仅听声音：只隐藏画面，不创建第二个控制器，也不改变当前位置、章节、队列或书签；该会话偏好会沿用到后续视频。倍速同样沿用到队列中的下一项；定时器在会话内切换媒体时继续生效，关闭播放器时取消。
- 带持久媒体资产的播放会话可读取和创建时间点书签。书签使用后端独立 `media_bookmarks` contract，记录明确内容、资产、毫秒位置和可选笔记；列表点击回到同一播放会话的准确位置，编辑与删除不改写解析得到的章节/逐字稿。
- 时间点书签将时间与更多菜单放在首行，完整笔记置于下方，避免时间和常驻编辑／删除图标将正文夹成窄列。无笔记时只显示时间；条目点击仍定位同一会话，编辑与删除放入根级圆角菜单。
- 时间点笔记复用 AdaptiveFormDialog：编辑／记录为标题，时间点单独作为次要信息。正常高度下操作位于底部，短横屏或键盘压缩空间后与正文一同滚动；尺寸切换保留草稿和焦点。弹层键盘自行避让，底层 `/player` 保持原尺寸和播放会话。未修改的笔记与放弃确认支持可撤回的预测性预览；有草稿时先询问，确认框返回只回到笔记输入。两个弹层均尊重减少动画设置。
- 笔记保存留在弹层内等待服务端结果，成功才退出；失败显示原因并保留文字，重试沿用打开时的时间点或原书签身份。保存期间禁用编辑、重复提交和退出。修改后取消、遮罩和系统返回先确认放弃；继续编辑或关闭确认框后，等待确认路由退出完成再恢复输入焦点，避免退出中的焦点作用域夺回焦点；文字保留，Web 同时启用整页离开提醒。同时间点冲突按稳定错误码提示返回编辑现有书签，不自动覆盖。
- 内容详情和 `/player` 读取同一播放请求携带的 `media_segments`。列表按当前资产过滤；章节与逐字稿同时存在时通过分段控件切换，各自按时间排序、独立高亮并可 seek，不再以章节覆盖逐字稿。只有一种时直接展示该类型。
- 时间段列表省略与标题完全相同的摘要，避免平台章节名重复占行；不同的补充说明继续显示。
- 逐字稿默认展示预览，点击条目展开可选择复制的完整原文；“从此处播放”显式定位并启动播放。章节与逐字稿列表分别建立滚动状态，切换类型不会复用另一类的滚动偏移。
- 文档和其他附件展示后端返回的原文件名、MIME 与大小；打开已知过期的本地签名来源前会按资产刷新一次 detail manifest，失败后才尝试下一候选。没有 OCR 结果时不把摘要或说明伪装成文档正文。
- 签名本地媒体、后端代理和允许直连的原图候选均不携带全局 API Token。
- `mapUrl()`、`mapPlayableUrl()`、图片专用鉴权头及其运行时调用方已经删除；前端不再把 `local://`、存储键或任意远端地址自行改写成媒体请求。
- 动态发现卡片、`rich_payload` 引用/子项图片和自动化队列封面已接入内容 `media_assets` 的有序候选；缺少匹配资产时显示占位或省略媒体，不读取旧字段直连。
- 详情媒体网格的翻页、缩略图选择和网格形状使用共享 `AppMotion` / `AppShape`；选中缩略图以尺寸、语义色边框和 tonal surface 表达，不再添加装饰性阴影。媒体页码与视频占位使用 inverse surface 颜色和 TextTheme 角色，深浅主题不依赖固定黑白文案样式。
- 全屏图集提供明确关闭、旋转、保存图片、上一张和下一张操作及语义标签。保存时刷新当前资产的 detail manifest，按已有候选顺序读取图片，再调用系统文件保存；资源读取不携带控制面 Token，失败不显示成功。Web 成功提示只表示交给浏览器下载；真实落盘及原生平台保存仍需各平台验收。
- 详情骨架与收藏列表骨架共用低干扰 pulse 节奏并尊重系统减少动效；全屏图集工具栏使用同一 shape 和 TextTheme 层级。

## 不承担职责

- 前端不应默认把所有外链都强制代理。
- 图片渲染不应阻塞在后端转码和本地缓存上。
- 失败态不应掩盖具体原因。

## 状态与输入输出

- 新输入：后端排好序的 `MediaSource[]`、媒体大小、图片尺寸和 fit 参数。
- 输出：一个活动媒体请求和同会话待播队列；单项失败时切换下一候选，全部失败后显示带稳定原因和手动重试的语义占位。
- 副作用：读取资源级签名或允许直连来源；仅 manifest 刷新和本地缺失核验进入已鉴权控制面。

## 响应式和失败态要求

- 桌面：缩略图、详情头图和媒体网格应保持稳定尺寸，不因加载失败改变页面层级。
- 移动：图片失败态不应挤压正文或遮挡操作按钮。
- 加载：显示低干扰 loading 占位；空、加载、失败和成功状态都保持调用方的尺寸与圆角裁切。
- 空状态：没有资产和 URL 时不请求网络，显示空占位且不提供无效重试；有持久资产时仍可刷新 manifest。
- 错误状态：按 HTTP 状态与来源类型区分签名过期、授权无效、本地缺失、远端不可达和格式不支持；不解析错误文案。使用中性表面，小缩略图以图标配合提示和语义标签表达，大区域直接显示原因与重试，不再叠加重复正文的 Tooltip；缩略图仍提供悬停/长按说明。错误区的重试焦点不随详细/紧凑布局切换重建，已打开的缩略图提示在切换为详细区域时移除。手动重试生成新图片请求标识，即使 URL 没有变化也重新加载；鼠标、触摸和键盘共用此动作。

## 尚未实现 / 计划扩展

- 图片 HTTP 失败已具备稳定分类；部分平台的原生音视频插件不会暴露 HTTP 状态，因此真实设备上的 410/404 分类仍需运行验收，不能由初始化测试外推。
- 分发消息已从统一资产/变体选择平台可用来源，Telegram/NapCat 不再读取旧 archive metadata/`cover_url`；真实 Telegram/QQ 媒体发送仍待授权环境验收。
- 后端签名 blob 的 Range、播放器运行期切源/进度恢复、应用内全局播放会话、重启后暂停恢复、同会话播放队列、倍速、定时停止、仅听声音、持久时间点书签，以及章节与逐字稿分别切换、定位的导航已有实现；当前长期回归保留签名/Range 访问和播放器暂停恢复，其余按变更专项验收。当前解析/摘要流程仍不生产这些时间段。睡眠定时器是当次运行状态，不跨重启恢复；仅听声音当前复用视频流并隐藏画面，不代表服务器已选择低带宽音轨；逐字稿正文来自经过校验的时间片段，不等于字幕轨渲染。真实 Chrome 已验证音视频解码、页面返回与浏览器历史返回继续播放、跨内容不抢播、队列自动续播，以及刷新后暂停恢复；继续播放时保留 1.5 倍速。Web 导航开始时保留播放意图，转场结束、视图移除后恢复同一控制器，明确暂停与定时停止优先；Android 后台播放与系统媒体控制的实现及验收见下文；长媒体连续播放、定时暂停、物理设备生命周期、PiP 和字幕轨仍待实现或验收。

全屏图集的缩放和翻页手势以当前图片为准；用按钮切到未放大的图片会恢复横向翻页，返回已放大的图片保留其缩放位置，非当前图片的变换不影响当前手势。旋转方向同样按图片分别保留，切图不重置上一张的方向，也不让离场图片在滑动途中转回原位；该状态限于当次图集，不修改原始文件。旋转沿顺时针连续过渡，快速点击从当前角度接续，第四次转回正向不反向回绕；画布随旋转适配当前窗口，工具栏与翻页按钮保持稳定。减少动画时直接到目标方向，切图后恢复已保存的方向，不重播进入动画。

全屏图片双击以点击位置为锚点放大至 2 倍，再次双击恢复原始大小；不从左上角放大而把用户选中的细节移出屏幕。

双击缩放沿当前变换平滑过渡，手动触摸缩放/平移或切图会停止旧过渡。短距离上下拖动松手与手势取消都平滑回位，再次拖动可接管正在回位的图片；减少动画时直接设置终态。超过现有关闭距离仍返回来源，不另造页面退出动画。

图片上方的操作条、左右切图按钮、页码和详情缩略图条复用 `core/widgets/media_overlay_surface.dart`。媒体覆盖层统一高对比深色表面，普通操作组采用随实际高度形成的胶囊轮廓，单按钮自然形成圆形，图标触控区域至少 48dp。缩略图条保留与内部图片 12dp 圆角加 8dp 留白相配的 20dp 外圆角；不把承载图片的容器机械改为胶囊。全屏工具组与两侧按钮避让系统安全区，大字号下页码让位于可操作按钮。详情悬停和缩略图选中变化也尊重减少动画设置。

全屏图集工具栏提供放大/还原，围绕当前可视区域中心在原始大小与 2 倍之间切换，复用双击的可中断缩放；双击仍围绕触点。键盘可 Tab 聚焦并用 Enter 操作，标签随当前缩放状态变化且保持按钮焦点。图集局部采用深色主题及浅色系统栏图标，加载/失败占位与媒体背景一致，关闭后恢复来源主题。

正文、单/双图、九宫格和焦点大图入口复用 MediaImageButton，标明图片序号及总数；横屏缩略图同时暴露选中状态。可 Tab 聚焦、Enter 激活，焦点描边绘制在图片上方并沿用图片轮廓，避免被不透明图片遮住；关闭图集后恢复来源焦点，失败原因与重试语义继续保留。全屏图集支持左右方向键切图、Esc 返回来源页；快捷键仅作用于当前图集焦点范围，首尾页不越界，鼠标按钮与键盘共用翻页逻辑。

全屏图集路由复用平台 Material 转场，同时保留透明路由以支持拖动时露出来源；不再自定义固定淡入。系统减少动画时关闭图片 Hero，方向键直接切页。Android 专用模拟器已验证边缘返回的中间预览、取消恢复和提交回原详情，见界面动效续接执行记录；原生首次 ADB 方向键曾未切图，后续输入正常，真实外接键盘仍需交叉验证。

待播列表点选条目会立即切换并开始播放，与“立即播放”和播完续接保持一致；被选中项从待播列表移出，其他项顺序保留。应用重启仍以暂停状态恢复，不因这项主动播放修复改变恢复策略。Android 专用模拟器已验证添加去重提示、两项拖动换序、移除末项、重启保留待播项，以及音频结束后接续视频（沿用仅听声音）；长队列跨屏拖动已另以 30 项组件样本补验，后台续播和真实设备交叉验收仍待继续。

播放器信息区与待播列表共用一个滚动区域，队列使用 Sliver 按需构建；拖动停在可见区域边缘时自动滚动，不再嵌套禁止滚动且整体撑开的列表。拖动浮层使用共享圆角与主题表面。Android 30 项临时组件样本已验证竖屏首项移到末尾、反向拖动取消后保持顺序、再次提交恢复首项，以及横屏 2 倍字号跨屏拖放；临时样本不读取或写入真实播放快照。

拖动浮层限制在信息区边界内，上下保留窄的滚动触发空间；即使触点移到系统手势区域，浮层仍不覆盖手势条或上方播放控制。额外边界专项验证自动滚动与取消顺序不受影响；正常 Android 播放页已用真实待播项复验底部拖动并取消。

播放器加载、失败及待播选择共用带圆角的主题表面；失败提示不再直接放在黑色视频画布上。待播选择按实际文字和按钮高度布局，不固定 176 高度；区域受限时提示内容与操作整体滚动。加载仍保留音频/视频的基础占位高度，受父布局限制时收敛到可用高度；失败图标、说明及重试留出内边距，使用相同文字主题。


## Android 后台播放与系统媒体会话（2026-09-12）

AndroidMediaSession 通过 audio_service 0.18.19 将系统播放、暂停、停止、定位、倍速与下一项转给既有 GlobalPlaybackController。UI 和系统会话共用 ProviderContainer 与 VideoPlayerController，不增加解码器或媒体 URL 获取路径；系统元数据只包含内容/资产身份、标题和时长，不包含资源签名 URL。Android 的 VideoPlayerOptions 开启 allowBackgroundPlayback，其他平台不改变生命周期策略。

播放时使用媒体前台服务，暂停时退出前台并释放播放唤醒锁；媒体通知仍允许恢复播放。停止关闭现有会话和队列，媒体会话不再活动。点击通知进入 `/player`，已处于该页时不重复压栈。MainActivity 继承 AudioServiceActivity，保留原分享 intent filters。

ExoPlayer 保持原有音频焦点管理；audio_session 0.2.4 只监听输出断开事件并暂停，不重复申请音频焦点。初始化期间的明确暂停会使原自动播放意图失效，避免媒体加载完成后突然发声；此竞态保留长期回归。

Android 36 专用模拟器已用现有短音视频验证后台、熄屏进度推进，通知/锁屏播放暂停和定位、后台下一项、通知进入播放页，以及暂停后释放前台服务并从后台恢复、停止后清空活动会话。物理耳机拔出、蓝牙、来电/其他应用焦点竞争、长媒体、系统回收与 PiP 仍未验收。模拟器拒绝发送受保护的 AUDIO_BECOMING_NOISY 广播，不能据此声称真实输出断开已验证。官方接入依据：[audio_service](https://pub.dev/packages/audio_service)、[audio_session](https://pub.dev/packages/audio_session)。


## Android 画中画（2026-09-12）

支持设备上的视频播放页提供画中画操作，可见且正在播放的视频回桌面自动进入系统小窗；暂停、音频或仅听声音不自动进入。小窗复用同一解码器和系统媒体会话，隐藏应用内工具与页面内容；展开恢复原来源，关闭小窗暂停。原页面保留导航、布局与状态，不按小窗尺寸重排后丢失位置。未支持设备和其他平台不显示入口。

Android 36 模拟器已验证显式/自动进入、系统小窗播放、拖动、关闭暂停和展开进度恢复，以及小窗态接收文本分享后回前台显示表单。接入依据为 [Android 官方画中画文档](https://developer.android.com/develop/ui/views/picture-in-picture)。转场抽帧仍发现进入/展开时黑色背景及视频尺寸衔接不够连续，未视为动效完成；混合队列转音频、快速重复、手势取消、旧版本和真机仍待验收。记录见界面动效续接执行文档。


视频表面在高度受限时按原始比例缩小并居中，避免外部横向拉伸约束压扁画面；PiP 来源矩形取缩放后的实际视频范围，不包含两侧余白。Android 横屏 2 倍字号已复验，后续仍需优化小高度下控制条与画面的空间分配。


视频控制条已移到画面下方，PiP 的早期进入回调保留原页面和视频尺寸；原生窗口实际缩小后才显示纯视频布局，避免把尚未缩小的页面先变为黑色画布。窗口没有声明 seamless resize 能力。原生视图回到当前路由时立即挂载已有视频，Web 继续等待旧页面释放唯一 HTML 节点。连续三次小窗进入/展开及播放页回桌面手势撤回已有 Android 36 录屏/状态验证；展开起点短暂黑帧仍待修复，不算完整动效验收。


原生视频按 TickerMode 判断可见性，打开倍速等非全屏弹层时保持已挂载的视频画面；完整页面覆盖或原页面 Offstage 后释放视图，返回时恢复。Web 按根导航栈中最上层的 PageRoute 交接唯一 HTML 视频节点；普通菜单和对话框不接管底页视频，全屏图集等完整页面仍参与交接。Android 横屏 2 倍字号已验证两栏、信息区滚动及倍速弹层不再造成黑色视频。


Web 普通弹层不触发为节点移除准备的暂停/恢复。页面跳转与异步目标视频挂载共同保留同一次播放意图，以最后一段实际挂载完成作为恢复边界；旧交接完成不能提前恢复，用户明确暂停或更换控制器也不会被旧回调覆盖。Chrome 实际倍速菜单连续开合三次无视频节点移除或暂停，书签弹层保留画面，详情往返后续播已验证；过渡中仍可能暂时没有已挂载的视频节点，未认定为无缝转场。对应 Chrome 竞态回归位于 playback_restore_test.dart，默认 VM 执行会跳过该 Web 专项。


视频与播放控制共用统一圆角表面，控制条位于画面下方，不再用半透明矩形遮住视频。高度受限时先为控制保留实际布局空间，画面按比例缩小；画中画来源只测量实际视频矩形，不包括控制条和两侧空白。

音视频进度共用主题 Slider，提供“播放进度”及当前/总时间语义、键盘方向键与触摸拖动，显示已缓冲范围；拖动期间预览目标时间，释放后通过既有会话 seekTo 定位并保存位置，不改变用户当前的播放或暂停意图。时间文字在大字号窄区域按需换行，未知时长禁用调整。


Flutter 3.47 的 Web 引擎把 Slider 名称放在外层语义元素，内部 HTML 滑块缺少名称关联。Web 启动脚本 `web/accessibility/slider_label_association.js` 将滑块通过 aria-labelledby 关联到现有名称；时间值、焦点和输入继续由 Flutter 管理。名称变更自动同步，名称移除时清理关联，新节点自动处理；引擎自行提供名称时保留其原生关联。真实 Web 视频与仅听声音展示均已按“播放进度”名称定位并用方向键调整，焦点和时间值正确更新。后续 Flutter 升级若已修复此引擎缺口，应移除启动补丁并复验；不要求锁定 SDK 版本。


音频及“仅听声音”展示与播放详情、会话控制和队列共用连续滚动区域，不再占用固定 45% 高度。可用内容高度不足 480dp 时，音频控制区随页面滚动，为大字号下的详情和操作留出空间；更高窗口使用带页面底色的停靠标题，滚动队列时仍能调整播放。尺寸切换复用原滚动状态和播放控制器。


倍速与定时入口采用胶囊形触发区、局部 Material 和至少 48dp 点击面积；定时当前值旁显示菜单箭头。焦点、悬停、按下反馈沿触发区形状绘制，选项菜单按自身主题圆角裁切。两者使用根菜单并尊重减少动画设置，取消后保持当前值。
