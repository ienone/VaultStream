# 前端导航与页面层级

## 文档状态

active

本文记录当前路由。主目的地按动态、收藏库、来源、推送组织，Agent、消息、内容处理和设置作为壳内工具。

## 当前实现

路由定义位于 `frontend/lib/routing/app_router.dart`，外壳位于 `frontend/lib/layout/app_shell.dart`。

Root Shell 主导航分支：

- `/home`: 动态页；`/home?item=ID` 在同一工作区阅读内容，关闭恢复动态列表。
- `/collection`: 收藏库。
- `/collection?item=ID`: 收藏库内选中内容；宽屏列表与阅读器并排，窄屏显示阅读器，关闭或返回恢复列表。
- `/collection/:id`: 独立收藏内容详情，用于外部深链和跨页面结果。
- `/collection/:id/edit`: 内容编辑，位于详情的根 Navigator 子路由。
- `/sources`: 订阅来源、名称搜索和类型／启停筛选；全局筛选保留策略位于 `/settings?tab=discovery`。
- `/accounts`: 来源工作区的连接账号页签。
- `/sources/sync`: 来源工作区的收藏同步页签。
- `/settings?tab=processing`: 内容处理策略。
- `/automation/distribution`: 待发送队列；其下 history、rules 与规则编辑共用同一个分发 Shell，只更新右侧内容。
- `/automation/distribution/rules`: 自动规则列表，编辑地址保持不变。
- `/automation/distribution/history`: 推送历史。
- `/automation/distribution/targets`: 跨平台推送目标。

已删除旧路由：

- `/automation`: 内容处理已归入设置，不保留重复入口。
- `/dashboard`: 不再保留到 `/home` 的兼容 redirect。
- `/inbox`、`/discovery`: 不再保留到 `/home` 的兼容 redirect。
- `/review`: 不再保留到 `/automation` 的兼容 redirect。

工具入口：

- `/accounts`、`/accounts/:platform`: 来源工作区的账号页签与单平台详情；宽屏保留列表，详情原位展开。`?from=sync` 保留收藏同步上下文与返回位置。
- `/sources?edit=new`、`/sources?edit=ID`: 在同一工作区添加或编辑订阅，跨宽窄屏保留草稿与列表筛选。

- 捕获 surface：由主页共用的页头保存按钮打开；它不是独立业务分支，应用内与系统分享共用同一 adaptive surface。
- `/connect`: 初始连接页，路由守卫在未初始化时可能跳转到这里。
- `/settings`: 设置，由侧栏或同源导航抽屉进入。
- `/tasks/:runId`: 后台任务结果。
- `/agent`: Agent 工作台，由侧栏或同源导航抽屉进入。
- `/player`: 独立播放设置页，保留时间点书签、待播队列和仅听声音设置。底部播放条原位展开播放器，Android 媒体通知进入当前内容详情；已在该详情时不重复压栈。
- `/notifications`: 消息盒子，由全局工具组切换到侧栏右侧的完整工作区，保留同一导航壳并高亮消息入口；使用独立状态分支，但不增加手机底栏目的地。
- `/events/:id`: 跨模板事件详情，由内容详情中的所属事件或加入事件结果进入。

## 承担职责

- 提供四个主业务入口：动态、收藏库、来源、推送。
- 提供工具入口：Agent 工作台、消息盒子、内容处理、设置，与主目的地在同一侧栏中分组；窄屏从主页页头打开同源抽屉。
- 侧栏固定使用 88dp 紧凑布局，移除布局菜单与模式偏好。窄屏保留四个目的地的底栏，工具由同样的紧凑导航抽屉进入；跨断点不替换主分支 Navigator。
- 支持部分深链接，例如自动化域入口、设置 tab、任务详情。
- 主分支通过 `StatefulShellRoute.indexedStack` 保留各自页面状态；普通分支切换不清空收藏库查询或筛选，只有收藏库的显式重置动作负责清空。
- 收藏库首次选择内容建立可返回的历史入口，后续选择替换当前地址，不为每条阅读内容积累页面栈。收折列表、调整宽度和跨断点保留同一个阅读器；独立详情仍使用同一 ContentDetailPage。
- 来源页签共享同一工作区；推送队列、历史、规则和目标共用分发 Shell。Agent 和设置也使用独立状态分支，桌面保持侧栏。返回逐层弹出，保留父页面筛选和列表状态；不再在 Shell 中按 URL 手工重定向模拟返回。
- 工具页、任务结果和通知中的主分支链接使用 `go` 切换到已有主导航；不使用 `push` 叠放另一套有状态导航壳。内容详情与工具链接仍使用 `push` 保留返回来源。
- 详情和工具使用的命令式导航会同步浏览器 URL；`/collection/:id`、`/events/:id`、`/tasks/:runId` 与 `/player` 在根 Navigator 展示。它们都保留可刷新、可分享的语义地址，返回时恢复发起导航的主分支状态。播放器与内容详情在同一导航层交接媒体视图，避免内部路由仍处于 current 状态而重复挂载同一视频节点。事件详情与任务结果保留自己的播放外壳；从根级内容详情进入时不再重新压入同一个外围 Shell 页面。

## 不承担职责

- 不决定业务策略。
- 不直接执行平台登录、同步、推送或后端写操作。
- 不在导航层承载跨页面状态迁移逻辑，除非是明确的 route 参数。

## 计划扩展

- 不在现状文档另立方案；页面职责与路由迁移以[前端目标设计](../plans/2026-06-10-frontend-information-architecture-redesign.plan.md)为准，跨端依赖与验收出口见[整体实施次序](../plans/2026-09-14-product-architecture-review.plan.md#sequence)。优先保留现有内容/事件地址和分支状态，不并存两套壳或同步编辑器。

工具页及账号/事件/任务详情在深链接刷新后保留返回入口；有来源栈时返回来源，无栈时回对应主入口。

连接页 `/connect` 不挂载 mini player；未连接时路由观察器不会恢复媒体会话。清除访问认证会同时关闭当前播放器，避免退出后继续播放或显示旧内容。

## 页面转场（2026-09-12）

独立内容详情与普通详情共用 Material 路由机制。普通详情在 Android 使用 PredictiveBack，iOS 使用 Cupertino，桌面使用水平 FadeForwards，替代桌面的中心缩放。收藏和动态不使用内容容器 Hero：宽屏在工作区内分栏，空间不足时 push 根级 MaterialPage，背景列表不重排，Android 预测性返回由实际页面路由承担。媒体详情不在异步加载后独立播放入场。系统手势事件的进度、取消与提交已在真实应用路由专项验收中通过；完整原生、嵌套导航、全屏媒体及弹层适配继续见专项执行记录。

Web 视频交接按根导航栈中的完整 PageRoute 归属判断；内嵌阅读器同时检查所属根页面和局部页面，避免根级播放器打开后子 Navigator 仍判定自己拥有视频节点。普通菜单/对话框不会夺走底页的 HTML 视频节点，也不会为弹层开合临时暂停。完整页面与全屏图集继续独占交接，实际目标视图挂载参与恢复播放时机，避免异步页面在路由动画结束后再次停播。

嵌套 Navigator 的 locally current 不等于当前可交互页面。外围 Shell 和主分支 Shell 通过 `AppNavigationScope` 传递祖先是否被覆盖；Android 页面转场的 PopScope 同时检查该作用域及分支 TickerMode。根弹窗覆盖时，子页面不得抢走返回手势；隐藏分支也不得被同一次手势弹出。继续使用 Flutter 的预测性页面转场，页面树不因作用域变化而替换，并与未保存表单的 PopScope 共同生效。

隐藏分支通过两处协作释放系统返回：Android 过渡拦截隐藏页面的 NavigationNotification；GoRouter 的祖先 Shell PopScope 仅在该分支 TickerMode 启用时阻止祖先弹出。`frontend/tool/dependencies/ensure_inactive_branch_back_navigation.dart` 在 pub get 后直接修改已解析依赖，开发安装与 CI 构建均执行；不复制路由器或锁死新版本，上游实现变化时需重新核对并更新或移除补丁。

Android 36 已验证保留分发子栈、切回动态后预览桌面，中途取消恢复首页，切回分支保留页面，提交返回桌面。规则草稿隐藏时同样不阻断首页预览；回到草稿后返回仍弹出放弃确认，继续编辑保留输入。修改返回行为时，需在实际页面核对可见根页拦截和隐藏草稿保护。此处不替代其他全屏媒体、弹层和连续手势的逐路径验收。

主导航的语义边界放在正文分支 Navigator 外部：嵌套页面的 ModalBarrier 会屏蔽同一语义容器里更早绘制的控件，原先连带隐藏左侧 NavigationRail，Android 横屏与 Web 均可复现。正文增加 Semantics(container: true) 后，侧栏与底栏保持可访问，根级弹窗依然屏蔽背景；不通过重排视觉布局或复制导航控件绕开。专项及真实端验收见执行记录。

## 内容编辑导航（2026-09-13）

详情菜单通过 push 进入 `/collection/:id/edit`，保存或返回后恢复来源详情。直接打开或刷新编辑地址时，同一父子路由建立详情返回入口。编辑使用平台页面过渡，不创建来源卡片 Hero。

页面返回与路由 onExit 共用未保存确认；浏览器历史返回选择继续编辑时恢复编辑地址与草稿，放弃才离开。编辑状态按路由实例及内容 ID 区分，切换另一内容先处理旧草稿，再加载新的编辑基线；认证失效允许退出私有页面。Web 刷新/关闭使用浏览器卸载提醒，未实现草稿跨重启持久恢复。原生完整预测性手势的进度与取消仍需分路径验收，普通返回通过不替代此结论。

外观设置中的许可列表及单组件许可正文沿用根 Navigator 的标准页面路由，层级为设置 → 许可列表 → 正文；返回逐层恢复来源，读者状态不因横竖屏或宽度变化而切换到另一套导航结构。此低频阅读入口没有独立深链，不加入主导航。

收藏库搜索直接在列表顶栏提交查询，不再维护窄屏专用搜索页或宽屏锚定浮层。搜索功能集中在收藏库，不再提供独立全局搜索入口或页面。

### 设置分区返回（2026-09-13）

设置保留原有 query 深链，通过内部标准页面栈表达列表与分区。窄屏页头和系统返回先回分区列表，再回来源；宽屏当前分区属于整个设置工作区，返回直接退出设置。内层返回能力仅在单栏时参与，根弹层覆盖时沿用导航可见性约束，避免同次手势弹出底下分区。

分区页面在单双栏切换时保留同一子树。宽屏清除分区参数后仍展示默认分区，缩窄后继续阅读该分区。六项专项覆盖返回、草稿、根弹层和 Android 预测性平台事件的进度／取消／提交；实际 Web 已查看标准转场及浏览器历史返回。原生设备与连续手势观感仍待验收。

全屏图集与展开播放器使用共享覆盖层路由；Android 边缘返回直接驱动现有图片 Hero 或播放器收折，取消恢复当前图像／播放会话。图集内部任意方向拖拽继续保留，系统手势不叠加另一层整页缩放。普通页面沿用平台转场，对话框、底部弹层和路由菜单由统一返回观察器接入。

来源、账号、规则、消息和阅读工作区的内嵌详情共用分栏返回预览；查询参数及局部选择用本地历史条目表达返回层级，包含子 Navigator 的详情登记实际叶子路由，提交仍经过原有退出处理。导航抽屉预览自身并由 Scaffold 关闭，打开期间正文分支不参与系统返回，避免同次手势连带关闭详情；锚定菜单先收起菜单，不连带关闭表单。减少动画时保留相同的返回结果。

本轮 Android 安装验收待正式签名文件及环境变量补齐；Web 操作验收不能替代系统手势验收。

推送待发送与发送记录通过 `?item=ID` 在宽屏保留列表并展开同一阅读器；关闭保留规则筛选和滚动位置。规则列表与编辑器持续挂载在共享工作区，新建入口位于列表内，打开与关闭沿用分栏过渡；窄屏编辑仍保留未保存草稿保护。
