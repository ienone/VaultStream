# 页面写操作失败与布局复核

## 状态

in_progress：已修复下列明确问题，完成主要 API、组件及已登录浏览器流程验收。2026-09-10 浏览器连接已恢复，后续被 Chrome 扩展弹窗阻断；剩余浏览器复核尚未完成，不作为全项目验收完成。

## 已确认根因与处理

1. 浏览器 `127.0.0.1:8877` 原先连接的 `8876` 是临时 `vault_adaptive_preview`。其中间件对所有非 GET/HEAD/OPTIONS 请求返回无响应体的 405，且 Uvicorn 禁用了 lifespan。消息已读、登录初始化以及其他写按钮因此统一失败。现已替换为正常 `app.main:app` 和正常生命周期，不在业务代码中绕过鉴权或写入策略。
2. 正常启动恢复数据库访问密钥后，浏览器保留的预览凭据失效。客户端之前只逐页报错；现在收到明确的 `invalid_api_token` 后清除当前失效凭据并返回连接页。旧请求的迟到错误不能清除新保存的凭据；无业务响应体的错误保留 HTTP 状态。
3. 三个主页的全局工具原先在所有宽度都进入菜单。medium 及以上直接显示搜索、Agent、消息、账号和设置；手机竖屏保留菜单。收藏搜索在 large 以下独立成行，避免挤压。
4. 任务结果技术详情使用 ExpansionTile 默认居中交叉轴，导致 Run ID/类型/触发来源错位。改为统一左对齐，去除展开默认边线；宽且高度充足时业务结果与运行信息并排，短横屏单列。技术详情在响应式切换时保留展开状态。
5. 登录对话框缺少短屏滚动，取消也没有覆盖系统返回与初始化响应晚到。现支持滚动、退出清理和迟到会话回收；状态读取失败重试同一会话，过期才新建。服务器连接表单也支持滚动，并避免离开后更新已销毁页面。
6. 消息筛选与列表原先在宽屏采用不同对齐范围。现统一居中；尚未读取消息时不启用全部已读。
7. 真实连接页会挂载旧 mini player，显示之前内容及媒体加载失败。认证页现不挂载播放层，未认证时导航观察器不初始化播放会话；清除认证关闭已有播放器。
8. 小红书另有本机缺失 Playwright WebKit 的环境失败。已安装项目实际使用的 WebKit 2336，复验可以返回二维码。

9. 任务、通知和账号详情把主导航分支再次 `push` 入栈，会出现地址正确但正文空白。主分支改用 `go`，工具和内容详情继续 `push`。搜索人物/主题跳转收藏筛选同样修正。
10. 外层播放 Shell 使用的 `matchedLocation` 在命令式导航后可能仍是旧位置，导致重复 mini player。改用当前 `state.uri.path` 决定归属。
11. 搜索提交原先使用 `go`，会清掉来源页面并失去返回按钮。改为 `replace` 更新查询；工具页和账号/事件/任务详情在深链接刷新后也提供明确返回目的地。设置退出删除不存在的 `/login` 跳转，由既有认证守卫返回连接页。
12. 短横屏扫码弹窗虽然可滚动，二维码仍会被截断。短横屏去掉装饰图标，将二维码与状态并排，按高度缩放二维码，保留取消和安全验证入口。
13. Agent 回答后插入用量事件时，final 再次追加同一回答。现在按当前用户轮次定位回答并原位替换，不依赖列表最后一项；历史轮次保留。回答复用 Markdown 渲染，内容/事件内部链接可导航，外部链接沿用安全打开工具，模型图片不自动抓取。
