# 已关闭问题的历史决策

这些结论来自已归档的修复记录，仅保留仍有参考价值的职责与设计决策，不代表当前版本已全面验收。旧复现过程、测试数量和截图不再常驻文档目录，必要时从 Git 历史查阅。当前事实见[前端文档](../../frontend/README.md)、[后端文档](../../backend/README.md)；近期界面证据见 [UI 审校报告](../../knowledges/ui-review-2026-09-13/README.md)。

| 历史问题 | 保留的决策与边界 |
| --- | --- |
| 9 月 6–7 日独立复审和布局整改 | 统一导航、设置连续表面与真实动作，删除占位和重复信息。旧截图已被后续界面取证覆盖；旧本地验收不证明原生设备或外部平台效果。 |
| Review 与自动化命名分裂 | 按自动化职责统一目录、类名与路由，不保留旧 Review 双路径。 |
| Agent API bridge 权限过宽 | 通用写桥接使用明确方法与路径集合；外部副作用经专用工具与业务策略。客户端自报 confirmed 不能代替持久确认。 |
| Bot router 承担外部副作用 | 配置保存与运行时同步分别表达结果；进程控制、群组同步及任务记录由 service 承担。配置保存不等于 Bot 在线。 |
| 动作 API 匿名字典 | 响应依照真实行为定义命名契约；同步完成、异步受理及无响应体 204 不强行统一。 |
| 数据库版本与结构漂移 | 版本号不替代结构检查；每个迁移仅记录自身版本，元数据初始化不能虚报完成最新迁移。 |
| System router 职责过多 | 跨域编排与外部调用进入 service；不为单纯减少文件行数再拆同领域短查询。 |
| 测试价值密度低 | 保留权限、外部副作用、数据完整性与关键竞态回归，临时探针不进入默认测试；不以数量证明保障程度。 |
| 收藏卡片到详情转场 | 来源与内容身份一致才建立视觉连续关系；阅读与媒体页面按真实职责处理，不能用统一动画遮盖数据加载。 |
| 收藏同步重试绕过开关 | 重试与批量入口必须同样服从平台 enabled 策略，界面禁用不是唯一执行边界。 |
| 账号入口重复 | 平台账号健康、登录和修复由账号中心承担，设置负责应用连接与低频配置。 |
| Agent 页面与 SSE 耦合 | 会话与流式事件由 controller/provider 管理，页面负责呈现、输入和确认；真实协议优先于动态字段猜测。 |
| 自动化页职责过载 | 同步、分发、解析/后处理分别组织；运行结果由任务页承接，避免总览复制全部操作。 |
| 前端开关未约束后端 | 开关必须作用于 worker、服务和 Agent 的实际入口；运行中与后续任务的语义分开。 |
| 动态页内容不足 | 动态服务近期发现和事件变化，不以迁移说明、假统计或系统健康信息充当内容。 |
| Discovery 与收藏详情耦合 | 候选身份及操作边界必须明确，共享内容呈现不等于共享收藏写操作。 |
| Discovery 占位工作流 | 没有真实能力的动作应移除，不能把导航或提示冒充执行成功。 |
| 同步占位策略 | 只展示后端实际支持的同步能力与策略，不给未实现选项制造可操作假象。 |
| Material 3 样式散落 | 基础形状、颜色、排版与动效复用主题语义，保留媒体、二维码等具体用途的必要差异。 |
| 主导航与工具混杂 | 区分主要目的地与页面工具；历史导航数量和位置属于当时方案，不约束未来重新设计。 |
| 阅读页承载处理流水线 | 阅读内容优先；后台诊断和工作流回到自动化/任务入口，删除面板不代表删除后端能力。 |
| UI 直接写 API | 页面处理输入和反馈，领域 provider/controller 处理请求契约、状态与刷新，避免重复封装。 |
| 媒体代理策略由前端猜测 | 后端提供资产与有序来源，前端消费明确候选；代理缓存不能改变已验证响应，保留 SSRF 等边界。 |
| 任务结果缺少业务表达 | 复用持久 run 与明确 presentation，技术 JSON 按需展开；任务账本不自动等于崩溃恢复或任务重放。 |

详细当前契约和剩余问题在所属模块维护，本页不维护新的待办和验证计数。
