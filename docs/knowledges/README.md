# Knowledges

## 文档状态

active

本目录存放知识库性质资料，不直接代表当前实现计划。

## 内容

- `adapters/`: 平台适配器知识和解析策略。
- `eval/`：RAG/语义检索评估数据。
- `ui/`：外部产品界面组织研究与可复用设计结论。
- `archive-summaries.md`: 旧审计、历史计划和归档文档的汇总。

## 使用规则

- 平台行为、URL 规则、字段映射、解析策略放这里。
- 如果要基于知识库开始实现，必须先在 `../plans/` 建 plan。
- 如果知识库描述和代码不一致，以当前代码为准，并创建 issue 或 plan 处理。
